# Proposal

## Why

节点管理列表刚交付的列个性化（横向滚动兜底、表头拖拽调宽、表头拖拽移动、常显握把线、全表竖线分隔、重置入口）经用户逐轮真机评审验收。上游管理与路由管理两个独立列表页存在同样痛点（无横向滚动、列宽不可控、小屏挤压），且两页与节点页同为高频运维列表——按用户裁决（2026-11-14：#/名称固定左、操作固定右；竖线一并推广；仅独立列表页，集群 Tab 子表后续另行立项）推广落地。

## What Changes

- **抽取复用 composable**：NodeList.vue 内联的拖拽调宽/移动/FLIP/光标逻辑抽取为共享 composable（拖拽起始冻结几何 → 实时换位 → FLIP 补间 → Esc 取消 → 全程 grabbing 光标），NodeList 改为消费方（行为零变化，测试护航）。
- **上游管理列表接入**：横向滚动 + `#`/名称固定左、操作固定右 + 默认宽度档 + 拖拽调宽/移动 + 竖线分隔 + 页头「重置列宽」入口。
- **路由管理列表接入**：同上；**新增技术点**——路由列带 `sorter: true`（表头点击排序），拖拽移动需在拖拽后抑制误排序点击。
- **竖线分隔推广**：节点页试点的全表内部竖线样式抽取为共享表格类，三页统一。
- 不做：集群 Tab 子表（另行立项）、列显隐接入（两页暂无此需求）、密度预设。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `table-column-resize`: ADDED「上游与路由列表的列宽个性化」需求（固定列选型按页、默认宽度档、重置入口）。
- `table-column-order`: ADDED「上游与路由列表的列顺序个性化」需求（含排序表头的拖拽手势冲突抑制）。
- `table-column-resize`: ADDED「竖线分隔推广」——节点页试点样式抽取共享表格类并覆盖上游/路由列表。

## Impact

- 前端：新增共享 composable（自 NodeList.vue 抽取）、`NodeList.vue`（改消费方）、`UpstreamList.vue`、`RouteList.vue`、共享表格竖线样式（style.css 或等价单点）。
- 测试：composable 单测迁移/新增、两页组件测试（调宽/移动/固定列/竖线类）、sorter 冲突用例；全量回归；真机验收脚本扩展上游/路由段。
- 零后端、零新依赖。
