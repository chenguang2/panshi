# Spec Delta

## ADDED Requirements

### Requirement: 上游与路由列表的列顺序个性化

上游管理列表与路由管理列表 SHALL 支持表头拖拽移动列：实时换位预览（跨边界即落位）、源列表头高亮、Esc 取消恢复拖前顺序、可拖列悬停抓取光标；固定列不参与移动。路由列表拖拽移动后 SHALL NOT 触发表头排序。

#### Scenario: 路由列表拖拽移动后不触发排序

- **WHEN** 用户在路由管理列表按住「URI」表头标题拖拽移动到目标位置松开
- **THEN** 列顺序 SHALL 生效，且 SHALL NOT 因拖拽经过表头而改变排序状态

#### Scenario: 上游列表实时换位

- **WHEN** 用户在上游管理列表按住「目标节点」表头标题拖动、指针跨过「协议」列左边界
- **THEN** 「目标节点」列 SHALL 实时换位至「协议」之前（无需松手）

#### Scenario: 刷新后顺序保持

- **WHEN** 用户调整列顺序后刷新页面
- **THEN** 列顺序 SHALL 保持
