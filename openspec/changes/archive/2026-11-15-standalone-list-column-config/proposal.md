# standalone-list-column-config

## Why

统一管理页的节点/上游/路由三张 Tab 子表都带「列配置」弹窗（选择显示列：显隐字段 + 搜索框开关 + 重置列宽），但左侧菜单的三个独立列表页里只有节点管理有；上游管理、路由管理的工具条只有一个孤零零的「重置列宽」按钮，缺字段显隐与搜索框开关能力，同一份数据在两处入口的配置能力不对等（用户反馈：需要统一）。

## What Changes

- 上游管理（`UpstreamList.vue`）、路由管理（`RouteList.vue`）工具条新增「列配置」弹窗，结构与节点管理同款：标题「选择显示列」→「显示字段」勾选组 →「搜索」显示搜索框开关 →「拖动表头右缘可调整列宽」提示 →「重置列宽」按钮。
- 两个页面的工具条「重置列宽」独立按钮移除，重置入口收进弹窗（与节点管理一致，避免同一动作两个入口）。
- 序号列（`#`）三张独立列表页统一不进弹窗、恒展示：`upstream-list-page` 规格已钉定序号列不进列配置弹窗，同时 antd CheckboxGroup 交互会把不在选项列表里的值从已选集合剔除，若不兜底序号列会被静默隐藏。节点管理同步对齐（原弹窗含 `#` 勾选项）。
- 列顺序计算改为共享纯函数 `resolveOrderedColumns`，显隐过滤 + 宽度覆盖统一走 `applyColumnWidths`，两页原先各写一份的 25 行重排实现删除。
- 存储键维持既有分立约定：`upstream_standalone` / `route_standalone` / `node_standalone`（与 Tab 的 `upstream` / `route` / `node` 互不影响）。
