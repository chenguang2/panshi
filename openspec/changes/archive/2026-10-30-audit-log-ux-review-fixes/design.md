# Design — 审计日志模块体验优化

依据：`AuditLog.vue`（572 行）、`backend/app/api/v1/system.py` 审计端点（150-320 行）、`auditResourceRoutes.ts`、dev 环境 `/audit-log` 真实截图 ×3（列表 / 详情抽屉 / 归档弹窗，2026-10-29）。样例页：`design-sample.html`（浏览器直接打开，静态展示优化后形态）。

## 1. 现状问题清单（按严重度）

| # | 级别 | 问题 | 证据 |

## 2. 信息架构（不变式 + 调整点）

页面骨架保持「头部动作区 → 筛选条 → 表格 → 分页」四段（全站一致，不动）；调整仅在三处：

1. **筛选条**：`[用户▾] [操作▾] [资源▾] [IP▾(新)] [日期范围+快捷项] [搜索框(新)] | 筛选结果 X 条 · 全库共 Y 条（最早 …）`，仍单行 nowrap（对齐约定 #43/AuditLog 既有注释）。
2. **头部动作区**：`导出 CSV`、`导出 Excel` | `归档历史(新)` | `归档清理`——归档历史与归档清理相邻，归档语义聚合；导出组与破坏性组之间保留既有分隔线。
3. **表格列**：`# 时间 用户 操作 资源 详情 IP`（资源列吞并资源ID）。

## 5. 争议点备选方案（已按推荐标记，待用户裁决）

1. **假排序治理**：A✅ 移除列头 sorter（时间倒序唯一语义；零后端改动）。B 后端 `sort/order` 参数支持任意列排序（审计页按用户/IP 排序价值低，加参数与测试面不划算）。
2. **资源跳转范围**：A✅ 高频资源映射 upstream/route/user/ssl_cert/node_task/autostart → 列表页（落地微调：node 无独立页面——节点列表仅存在于集群子页 /clusters/{id}/nodes，无法以节点 id 锚定，换 autostart /edge-autostart；cluster 保持详情锚定）。B 全量 40+（history 类与全局配置类无天然详情页，强映射会产生「跳过去什么都没有」的负体验）。
3. **关键字检索**：A✅ `keyword` = detail ilike + resource_id 精确（单输入框双语义，纯数字才触发 ID 匹配）。B 仅 detail ilike（ID 精确查已被「资源+ID」下拉部分覆盖）。
4. **IP 筛选**：A✅ meta 增 `ips` distinct + 下拉（与用户下拉同型；内网 IP 基数小）。B 不做。
5. **归档历史形态**：A✅ 独立抽屉列表 + 逐文件下载（`GET /operations/archives`）。B 归档弹窗里追加「历史存档」折叠区（入口深一级，不推荐）。

## 6. 交互流程

**导出（收敛后单路径）**：点击导出 → `total>50000` 先 warning → `POST /operations/export`（带全部筛选）→ 轮询 status（现同步 ready，保留轮询兼容）→ blob 下载（带 Authorization）→ success toast `已开始下载 CSV/Excel`。移除前端 ≤5000 分支（25 次串行请求路径、共享 exportToCsv 在审计页的使用）。

**归档清理（保持现有安全三件套，仅文案微调）**：选截止日期 → 只读预览（条数 + 时间范围）→ 确认归档（红按钮）→ 服务端先写 CSV 存档 + tombstone 审计再删除 → 自动下载 + toast。新增：完成后抽屉里的归档历史立即可见该文件（闭环可验证）。

**深链**：`/audit-log?resource=xxx` 预选机制保持不变（各页「操作日志」入口依赖）。

## 7. 状态展示规范

- **操作标签**（批 1 核心）：`删除/批量删除/删除历史/清理` → danger 弱色（红字浅红底）；`创建/批量创建/导入/生成/生成 CA/上传` → success 弱色（绿字浅绿底）；其余 → 中性描边（灰字透明底）。仅删除系用警示红，避免全页焦虑（现状无色，非减色）。
- **详情列**：默认模板 detail（`{resource} {action} (id=N)` 及 `(batch)` 变体）→ `—`；有内容 → 50 字截断 + tooltip 全文。
- **加载**：a-table 自带 loading；导出/归档按钮沿用现有 `:disabled + 文案态`。
- **空态**：a-table 默认；归档历史抽屉用上表文案。
- **IP 列**：保持 mono 12px；无 IP 显示 `-`（现状一致）。

## 8. 实现落点与守卫

- 前端：`AuditLog.vue`（列/筛选条/文案/导出流程/归档历史抽屉）、`auditResourceRoutes.ts`（映射返回 `{path}` 由页面 router.push；标签兜底改 `未识别（raw）`）、`api/auditLog.ts`（meta.ips、keyword、archives 两个封装）。

- 测试：AuditLog 组件测试（列合并/标签色/统计文案/导出确认与截断/归档历史抽屉）+ 后端（meta.ips、keyword 过滤、archives 列表下载、安全采样）；批 2 反转既有 sorter 相关断言。
