# edge-client-ux-review-fixes 提案

> 2026-10-30 Edge 直连模块 UX 评审（真实页面 Playwright 探测 + 代码行号证据；用户裁决待定项默认推荐 A）

## 背景与问题

Edge 直连页（`EdgeClient.vue` 2283 行，8 个资源 Tab + 三态节点选择）是节点调试主入口。实测暴露的核心缺陷是**失败反馈全面缺失**：节点不可达时页面照常显示「已连接」+ 空表格，用户无从判断连接是否成功。

**P1**：
1. **不可达节点 → 「已连接」+ 空表误导**（实测 `10.255.255.1:11999` 查询：8 路请求全部失败被单路 catch 静默吞掉（`EdgeClient.vue` 各 `loadXxx` 仅 `console.error`），无失败 toast、`已连接` 照常显示 + 空表 + 空态文案「未查询到数据，请确认节点可达」——`已连接` 与「请确认节点可达」同时出现自相矛盾；且两轮实测行为不一致（一轮显示已连接、一轮未显示）暴露 loadedNode 设置的竞态）
2. **未选节点点查询零反馈**（`loadAllData` `if (!node) return` 静默返回，实测 toast 空）
3. ~~长列表无分页~~（评审提出，裁决 B 保持全量渲染：调试场景需整表浏览，不纳入本轮）
4. **手动输入依赖 @blur**：`onManualInput` 只在 blur 更新 `selectedNode`；输入后直接点「查询」（鼠标点击先触发 blur 序列不可靠）存在值竞态——上轮实测甚至出现「已连接」显示与输入无关的旧值（10.255.255.101:9180，非本环境节点）

**P2**：
5. **编辑无绕过警示**：删除确认有「此操作绕过同步流程」，编辑弹窗直接改线上节点无任何警示（同属调试模式危险操作）
6. **spec 漂移**：主 spec `edge-client-manual-query` 写「SHALL NOT auto-load on mount / 6 parallel requests」，代码现状选节点即自动加载 + 8 路并行
7. 空态文案「未查询到数据，请确认节点可达或更换节点后重试」对「未选节点」「节点无数据」「连接失败」三态同文案
8. 手动输入 placeholder 示例 `192.168.100.235:11999` 与实际环境网段（192.168.0.x）不符
9. 搜索框用 🔍 emoji 图标（非 icon 组件，与全站 AntD icon 不一致）

## 改造清单

### 批 1 — 查询反馈与正确性（P1 治本）
1. **失败聚合反馈**：8 路 `loadXxx` 返回成败；`loadAllData` 聚合——全部失败：错误横幅「节点不可达或端口错误（ip:port），请检查后重试」+ **不设置「已连接」** + 清空数据；部分失败：warning 横幅「N 类配置获取失败：路由、SSL 证书……」其余正常；全成功：现状不变
2. 未选节点点查询 → warning toast「请先选择节点」（manual 模式输入为空同样提示）
3. **手动输入去 blur 依赖**：查询时直接读 `manualNode` 输入框当前值（v-model 已同步，无需中间 selectedNode）；`@blur` 语义移除
4. **「已连接」判定收紧**：仅当至少一路成功时设置 `loadedNode`；附「部分类获取失败」横幅（同 1）

### 批 2 — 一致性（P2）
6. **编辑弹窗补绕过警示**：各编辑弹窗顶部 info 提示「调试模式：修改将直接写入边缘节点，绕过平台同步流程」
7. **空态三态区分**：未选节点「请先选择节点后查询」；节点无数据「该节点上无此类配置」；连接失败「节点不可达，请检查地址与端口」（由批 1 的成败状态驱动）

### 批 3 — 观感与 spec 修正
8. 🔍 emoji → `SearchOutlined`（8 处搜索框）
9. placeholder 示例改 `192.168.0.14:16620`（本环境真实格式）
10. **spec 漂移修正**（delta MODIFIED）：auto-load 语义改为「选节点即自动查询，查询按钮用于手动刷新/手动输入」；6 路 → 8 路并行

## spec 变更摘要（openspec/specs/edge-client-manual-query）

- **MODIFIED**：Manual query trigger（场景改写：选择节点即自动查询；查询按钮语义=手动刷新）、Click query loads data（6→8 路 + 失败聚合反馈场景）、SSL 证书 Tab（保留）
- **ADDED**：查询失败聚合反馈 / 分页与表格规格 / 编辑弹窗绕过警示

## 待决项（2026-10-30 用户裁决）

1. **失败聚合反馈**：A ✅（全失败不设「已连接」+ 错误横幅）
2. **分页**：B ✅（保持全量渲染——调试场景常需整表浏览/搜索，20/页翻页反而碍事）
3. **编辑警示**：A ✅（弹窗内 info 提示，不打断）

## 影响

- 前端 `EdgeClient.vue` 单文件为主（8 路 load 函数改造 + 分页 + 文案）+ 测试扩展（现有 EdgeClientRouteLabel/EdgeClientSslPagination 回归）
- 无后端改动（8 个端点不动）；spec delta 修正漂移
