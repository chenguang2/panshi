# Design: ux-review-fixes

## 修复策略

照 H/M/L 优先级三批 TDD（每批一 commit），新增 41 项前端断言 + 5 例后端到期测试；勘误项（L4/L9/L12 等 5 项）经代码核实推翻 OCR 后入档报告，不修。

## spec 粒度取舍

评审 26 项中仅 4 组行为值得立 spec 需求（到期预警/标题术语/权重语法/登录引导）——它们是**可回归的行为契约**（后端字段 + 展示形态 + 文案锚点）；其余为一次性排版打磨，落 spec 只会制造维护噪声，由源码守卫测试（clusterStats.source.test.ts 等）钉死即可。

## 关键语义

- 到期徽章三态：`剩余天数 < 0` 已过期 / `≤ 30` 临期预警 / 其余正常显示「剩余 N 天」
- 标题对齐原则：**落地页标题须确认用户的点击**（菜单「DNS代理[UDP]」→ 标题「DNS 代理（UDP）」），侧边栏与页面术语必须一致
- 权重语法：全角括号「（100）」与上游列表统一，废弃 `:100` 冒号语法
- 忘记密码：本平台用户由管理员管理（无自助改密），引导文案指向「系统管理 → 用户管理」
