# Proposal: 节点任务 — 分发文件

## 概述

在节点任务中心新增「分发文件」操作类型，支持用户上传任意文件并分发到选中的 Edge 节点。

## 动机

运维过程中经常需要将配置文件、证书、脚本等文件批量推送到多个 Edge 节点。目前只能逐节点手动操作或依赖外部工具，效率低且易出错。通过节点任务中心的批量执行框架，可以一键分发到多个节点，并获得统一的日志、状态追踪和错误处理。

## 方案

复用现有 `master_copy_to_slaves.yml` Ansible playbook，通过 `ansible.builtin.copy` 模块将控制节点上的文件拷贝到目标节点。**多节点统一执行**（一次 ansible 调用覆盖所有选中节点）。

**核心流程：**
1. 用户在前端上传文件 → 服务端原样存储到 `task-scripts/temp/{upload_id}`（不做编码转换）
2. 用户指定目标目录路径 → 创建 `distribute_file` 类型任务
3. 后端迁移文件到 `task-scripts/{task_id}/` → 一次性调用 `run_playbook`（所有节点 IP）
4. Ansible 将文件从控制节点拷贝到各目标节点的指定目录
5. 解析 ansible 输出，更新各节点子任务状态

**关键设计决策：**
- 复用 `master_copy_to_slaves.yml`，不需要新建 playbook
- 多节点统一执行（非逐节点调用），结果拆分到各节点记录
- 文件类型不限，原样字节传输，不做编码检测/转换
- 文件大小限制可调下拉框，默认 10MB
- destpath 始终为目录路径，文件以原始文件名存入

## 涉及的变更

| 领域 | 变更 |
|------|------|
| 后端路由 | 新增文件分发上传端点（独立于脚本上传，零编码处理） |
| 后端服务 | 新增任务级执行路径（非 `_execute_node`），调用 `run_playbook` + 结果解析 |
| 前端 API | 新增文件分发上传模块 |
| 前端 UI | NodeTaskCenter 新增「分发文件」操作类型 + 已上传文件列表/删除 UI |
| Ansible | 复用 `master_copy_to_slaves.yml`，无需修改 |

## 风险与缓解

| 风险 | 缓解 |
|------|------|
| 大文件传输超时 | 可调文件大小限制 + 可配 timeout |
| 目标路径不存在 | copy 模块自动创建父目录 |
| 单节点失败 | 不中断其他节点，各节点独立状态 |
