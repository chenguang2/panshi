## Why

表格视图存在三个可用性痛点：「自定义字段」列在绝大多数行只显示"—"，占用一整列却几乎不传递信息；「＋ 添加主机」按钮位于顶部工具栏，点击后新行追加到表格底部，IP 较多时新行在视口外，用户以为点击无效；逐台录入主机在批量初始化场景下效率低。

## What Changes

- 移除「自定义字段」独立列：改为「高级」按钮上的橙色圆点徽标，tooltip 列出具体键名并说明仅源码模式可维护
- 「＋ 添加主机」从顶部工具栏移至表格底部通栏虚线按钮；点击后自动滚动定位到新行并高亮闪烁约 2 秒
- 回车续录：在最后一行（IP 已填写）的 IP 输入框按 Enter 追加新行，滚动定位、高亮并自动聚焦新行 IP 输入框；最后一行 IP 为空时不追加
- 新增「批量导入」弹窗（仅表格视图提供）：粘贴多行 `IP [SSH用户] [SSH密码]`（空白分隔即空格/Tab，支持 `#` 整行注释与行尾注释），实时解析预览与逐行错误提示；与现有行同 IP 时仅覆盖粘贴中提供的用户/密码字段（未提及的凭据与高级字段均保留）并在预览中标注；确认后填入表格走统一保存流程
