# Proposal — 用户管理模块体验优化（user-management-ux-review-fixes）

## Why

对用户管理页（`/users`，`UserList.vue` 1252 行）按易用性 / 易于理解 / 美观与层级 / 安全与风险感知四维做了体验评审（依据：真实代码、`users.py` 端点、`deps.py` 认证链、dev 环境真实截图 ×5）。核心问题：**4 处列头假排序**（后端无排序参数）、**admin↔user 角色切换清空权限勾选 = 误操作即丢数据**、**禁用用户无确认且即时踢下线**（`get_current_user` 对 status≠1 直接 401，已登录会话立即失效）、**重置密码无二次确认**（账号接管高危，且紧邻保存按钮）、**集群选择器「取消」按钮撒谎**（选择即时生效，取消不还原）、删除确认不说明级联清除后果。

## What Changes

按风险分三批（低风险文案/视觉先行，状态语义类靠后）：

**批 1 — 文案与视觉（纯前端，低风险）**
1. 错误文案补因：「操作失败」「删除用户失败」「加载用户列表失败」「重置密码失败」→ 说明原因与下一步动作。
2. 空态双形态：筛选无结果「无匹配用户 + 清除筛选按钮」；真空库才显示「暂无用户」。
3. 搜索框升级：🔍 emoji → `a-input-search`（回车触发 + 300ms 防抖，消灭每键一请求）；placeholder「搜索用户名」；查询前去首尾空格。
4. 角色/状态筛选原生 `<select>` → `a-select`（showSearch）。

**批 2 — 交互修复（前端为主，中风险）**
5. 假排序治理：移除用户名/角色/状态/创建时间 4 列前端 sorter（后端 `list_users` 无 order 参数，本页排序只重排当前页，跨页语义错误）。
6. 状态列升级：`BadgeStatus` 静态徽章 → 显式 `a-switch`（点击即发起切换，弹确认）；「禁用/启用」从 ⋯ dropdown 提升出来，dropdown 只留「删除」。
7. 禁用/启用二次确认（见 specs：确认文案说明「立即下线且无法登录」——后端 `deps.py:58` 已证实即时生效语义）。
8. 删除确认补后果：「将一并清除其资源权限与集群授权，且不可恢复」。

**批 3 — 状态语义（数据丢失防护，依赖交互重构）**
9. 角色切换权限快照：admin↔user 来回切换不再清空已勾选权限（现状 `onRoleChange` 直接清 `selectedPermKeys`——普通用户误切 admin 再切回、保存即丢全部权限）。
10. 集群 picker 暂存态：打开时快照当前选中，「确认」才应用、「取消」还原（现状取消即生效，按钮撒谎）。
11. 重置密码二次确认：确认弹窗说明「该用户当前密码将立即失效」（紧邻保存按钮的即时高危动作）。
12. 编辑保存三请求序列（update → permissions → clusters）中途失败的定位文案：「基础信息已保存，权限更新失败，可单独重试」。

## Capabilities

- **Modified Capabilities**: `user-management-ui` — 列表排序语义、状态切换交互、危险操作确认、角色切换权限保持、集群 picker 语义均属该 capability 的需求级变化（已确认主 spec 存在：`openspec/specs/user-management-ui/spec.md`）。
- **New Capabilities**: 无。

## Impact

- 前端：`UserList.vue`（列/筛选条/开关/确认弹窗/picker 暂存/权限快照）、可能新增 `UserList.test.ts` 扩展（现有仅 pagination 测试）。
- 后端：无接口变化（排序裁决 A 不加参数；全部行为语义前端收敛）。
- 测试：`UserList.pagination.test.ts` 既有断言保持；新增交互用例（排序移除、switch 确认、权限快照、picker 取消还原、重置密码确认）。
- 风险：批 2/3 反转既有交互（dropdown 菜单项、picker 即时生效）——按 #217 先 grep 消费方与既有断言再动手。

## 待决项（2026-10-30 用户裁决：全部采纳推荐方案 A）

1. **假排序**：✅ A 移除列头 sorter，列表恒按后端返回顺序。
2. **状态切换形态**：✅ A 状态列显式 a-switch + 确认弹窗（禁用文案说明即时下线）。
3. **集群 picker**：✅ A 暂存态（打开快照 / 确认应用 / 取消还原）。
4. **重置密码**：✅ A 二次确认弹窗。
5. **角色切换权限**：✅ A 保留勾选不清空（admin 时权限区不渲染但内存保留）。
