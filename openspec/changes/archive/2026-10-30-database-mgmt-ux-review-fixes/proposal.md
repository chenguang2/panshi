# database-mgmt-ux-review-fixes 提案

> 2026-10-30 数据库管理模块 UX 评审（真实页面 Playwright 探测 + 代码行号证据；实测含新建弹窗/测试/删除确认/切换确认全流程）

## 背景与问题

数据库管理页（`DatabaseManagement.vue` 536 行 + 两张摘要卡）整体骨架成熟——切换确认弹窗（重启指引/JWT/空库 admin/命令）、删除确认（「不影响数据库本身」安抚）、pending_restart 提示都已到位。实测暴露的问题集中在**假功能与状态语义**：

**P1**：
1. **新建弹窗「测试连接」按钮是假的**——`handleTestDraft` 只弹「请先保存连接，再点击测试」（DatabaseManagement.vue:326-334）；按钮存在功能不存在，用户点了被劝返。后端测试端点按已存 id 设计（database.py:282），草稿测试需新端点
2. **当前连接行「删除」可点**——后端 400 拦截（「不能删除当前激活的数据库，请先切换」database.py:272-273），但 UI 不知情：当前行删除钮照常可点，点了才报错
3. **SSL 配置死字段**——`connModal.form.ssl` 存在于表单状态与提交载荷（:251/:281/:321/:350），但模板**无任何 SSL 输入控件**：编辑回显后用户无法查看/修改，纯死代码
4. **测试失败 detail 直出英文异常串**——`_do_test_sync` 失败 detail 为 str(e)（如 `connection refused`/`password authentication failed`），非技术用户不可读；超时已有中文「连接超时」（database.py:296）

**P2**：
5. **「设为当前」全表主色**——非当前行 10 个 `btn-primary`（截图 db-1），主行动作视觉被稀释；真正的高危确认在弹窗里
6. **地址列超长路径无省略**——SQLite 路径 `data/panshi.db.restored-20261008_015112` 全宽展示撑破表格节奏
7. **新建无重名提示**——后端无校验（database.py:213 直接 append），同名连接可无限堆积（现有「192.168.100.90」「qcg」等命名随意）
8. **状态点恒绿**——`.status-dot online` 无条件渲染（:18），未测试的连接也显示「在线」绿点，语义误导
9. **名称 placeholder 无示例**——「连接名称」无格式引导

**P3**：10. 连接表 11 行 `pagination=false`（小表白名单边缘，暂不接分页——记录不处理）；11. 删除/切换确认文案已达标不改；12. pending_restart 提示已达标不改。

## 改造清单（三批）

### 批 1 — 假功能与危险操作（P1）
1. **去掉新建弹窗内假「测试连接」按钮**：保存成功 toast 改「连接已添加，可点击列表中「测试」验证可用性」（编辑弹窗同步；后端不加草稿端点——低侵入）
2. **当前连接行「删除」禁用 + tooltip**「当前连接不可删除，请先切换到其他连接」；「编辑」保留（改名/地址可编辑）
3. **补 SSL 开关**（postgres 表单，checkbox「启用 SSL 连接」），编辑回显真实值
4. **测试失败 detail 中文转译**（后端 `_do_test_sync`）：connection refused→「连接被拒绝（服务未启动或端口错误）」、authentication→「用户名或密码错误」、database does not exist→「数据库不存在」、其余保留原始信息并加前缀「连接失败：」

### 批 2 — 视觉与状态语义（P2）
5. 非当前行「设为当前」降为 `btn-secondary`（当前行动作收敛：测试/设为当前/编辑同级次级样式，主色只留「+ 新建连接」）
6. 地址列 max-width + ellipsis + title 悬浮完整路径
7. 新建/编辑保存前重名软校验（前端比对现有列表 name，提示「已存在同名连接」阻断）
8. 状态点语义：`online` 绿点仅当最近一次测试成功；默认中性灰 + tooltip「未验证连通性」；测试成功/失败更新该行状态点（内存态，刷新重置）
9. 名称 placeholder「如：生产 PG / 本机 SQLite」

### 批 3 — spec 同步
10. delta MODIFIED：测试连接失败（detail 中文分类转译场景）、删除激活中的连接（UI 禁用前置场景）；ADDED：连接表单 SSL 配置、重名校验
