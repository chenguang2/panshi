## Context

`AnsibleInventory.vue` 已实现表格 ⇄ 源码双视图、组级默认凭据卡片、行展开高级设置与全保真保存。当前表格列为 IP / SSH 用户 / SSH 密码 / 高级 / 自定义字段 / 操作；「＋ 添加主机」在卡片标题行右侧，点击 `rows.push` 追加到数组尾部。后端 hosts 以 IP 为 YAML 映射键（重复键天然合并），保存校验含删除保护与任务互斥 409。

## Goals / Non-Goals

**Goals:**

- 消除「自定义字段」列的空间浪费，同时保留"该行有表格不可编辑的键"这一关键提示
- 添加主机后用户能立刻看到新行（滚动定位 + 高亮）
- 支持连续录入（回车追加）与批量粘贴导入，降低多 IP 场景的录入成本

**Non-Goals:**

- 不改双视图切换、保存/删除保护/409 互斥、离开护栏等既有流程
- 不做抽屉/弹窗式逐台编辑表单
- 不新增第三种"快速文本"常驻视图（批量导入弹窗已覆盖该需求）
- 后端 API 与载荷结构不变

## Decisions

### D1. 自定义字段标记折叠进「高级」按钮

独立列 → 「高级」按钮叠加橙色圆点徽标 + tooltip（列出键名、"仅源码模式可维护、保存不丢"）。理由：该信息是低频状态提示而非高频操作入口，不值得独占一列；「高级」按钮已承载"此行有额外配置"的语义，徽标自然归并。顶部 unknown_keys 提示条保留（解释机制，可关闭）。备选：保留列但仅在有未知键时显示——仍占列宽，弃。

### D2. 添加主机 = 底部通栏虚线按钮 + 滚动高亮 + 回车续录

- 移除顶部工具栏按钮，表格下方放通栏虚线按钮（Ant Design 可编辑表格惯例），录入焦点始终在表格尾部附近
- 「追加并定位」为单一共享逻辑，两条追加路径（点击底部按钮 / 最后一行 Enter 续录）行为一致：`nextTick` 对新行 `scrollIntoView({ behavior: 'smooth', block: 'center' })` + 行加 2s 高亮闪烁动画类（动画结束移除）+ 聚焦新行 IP 输入框
- Enter 续录仅在最后一行 IP 输入框监听，且最后一行 IP 为空时不追加（避免堆叠空白行）；非最后一行回车不动作；输入法组合输入期间（`isComposing`）的 Enter 不触发
- 新行定位用现有 WeakMap 行键机制，通过 ref 记录"待定位行键"在渲染后处理

### D3. 批量导入为前端纯函数解析 + 弹窗预览

- 入口仅在表格视图工具栏提供；源码视图本身即批量编辑入口，不重复提供
- 解析逻辑放 `utils/ansibleInventory.ts` 纯函数 `parseBulkHosts(text)`：按行拆分，跳过空行；`#` 支持整行注释与行尾注释（拆分后遇到以 `#` 开头的 token 即丢弃其后内容，代价是密码首字符为 `#` 无法表达，此类场景走源码视图）；每行按空白拆分（空格/Tab 均可，兼容 Excel 粘贴）为最多 3 段（IP 必填，用户/密码可选）；返回 `{ entries, duplicatesInText, errors }`，errors 带 行号 与原因（缺 IP、段数超限、IP 不匹配等）；IP 校验使用与后端 `_HOST_KEY_RE` 完全一致的正则口径（宽松的主机名/IPv4 形态校验，非严格 IPv4 语义校验），不匹配的行逐行报错
- 文本内部重复 IP：后者覆盖前者，entries 去重；`duplicatesInText` 供预览提示「文本内 X 条重复已合并」
- 与表格现有行同 IP：仅覆盖粘贴中提供的 ansible_ssh_user/ansible_ssh_pass 字段（粘贴行未提及的凭据保持原值，不静默清空），高级字段与未知键一律保留；预览中标注「M 条将覆盖现有主机」
- 预览区实时显示「识别 N 条记录」（N 为文本内去重后的最终写入条数）+ 覆盖/重复提示 + 错误列表；列表中密码以固定长度掩码（••••）占位，不做明文回显；确认按钮在有错误时禁用
- 确认后新增条目追加到 rows 末尾并 markDirty，后续走既有保存/校验流程，不绕过任何护栏

### D4. SSH 用户/密码保持顶层列不变

最常用凭据值得常驻可见，placeholder「留空继承组级默认」已表达非必填语义；低频变量继续收在展开的高级设置中。维持现有信息分层。

## Risks / Trade-offs

- [滚动定位依赖 DOM 时序] → 用 nextTick + 行键 ref 兜底；a-table 无虚拟滚动，行数有限，风险低
- [粘贴格式歧义（密码含空格或以 # 开头）] → 明确约定空白分隔且密码不含空白、不以 # 开头，解析错误逐行提示；复杂情况引导走源码视图
- [覆盖现有行凭据不可逆] → 预览明确标注覆盖数量，且整页有未保存护栏（刷新/离开确认），未点「保存生效」前可刷新回滚
- [徽标语义弱于独立列] → tooltip 补全键名清单；源码视图仍是完整维护入口

## Migration Plan

纯前端改动，随前端发版即生效；无数据迁移。回滚 = 还原该页面与 utils 提交。
