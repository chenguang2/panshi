## ADDED Requirements

### Requirement: 备份页编辑态与已保存态隔离
备份管理页 SHALL 将「已保存状态」与「编辑中表单」分为两个数据源：状态区（调度徽章、下一轮预计、最近成功、不适用原因）MUST 仅读取服务端已保存配置与 status 数据；编辑表单的未保存修改 MUST NOT 改变状态区展示；存在未保存修改时页面 SHALL 显示显式「有未保存修改」标记，保存按钮与全局配置表单 MUST 在视觉上构成贴近的可操作单元；「刷新」操作在存在未保存修改时 MUST 先经确认，确认后放弃修改并重新加载。

#### Scenario: 未保存修改不污染状态区
- **WHEN** 已保存配置为启用、间隔 60 分钟，用户把表单开关拨到停用但未保存
- **THEN** 状态区调度徽章仍显示「已启用」、下一轮预计仍显示已保存配置的具体时间，页面出现「有未保存修改」标记

#### Scenario: 下一轮预计单一数据源
- **WHEN** status 返回 next_run_at
- **THEN** 状态区「下一轮预计」显示该具体时间而非配置间隔，且该值不随表单未保存修改变化

#### Scenario: 刷新脏守卫
- **WHEN** 存在未保存修改且用户点击「刷新」
- **THEN** 弹出确认（说明将丢弃未保存修改），确认后重新加载并清空编辑态，取消则保持现状

### Requirement: 立即备份未保存守卫与执行预期
「立即备份」在存在未保存修改时 MUST 弹出三选确认：保存并备份、按已保存配置备份、取消；选择「保存并备份」MUST 先保存成功再触发备份；执行期间按钮 MUST 锁定并显示耗时预期（按启用位置数给出推送范围提示）；触发被拒（409 已有任务进行中）时 MUST 展示后端原因且不静默。

#### Scenario: 脏状态下三选确认
- **WHEN** 存在未保存修改且用户点击「立即备份」
- **THEN** 弹出「保存并备份 / 按已保存配置备份 / 取消」三选，选择后按所选路径执行，取消不执行

#### Scenario: 按已保存配置备份提示
- **WHEN** 用户在脏状态下选择「按已保存配置备份」
- **THEN** 备份按服务端已保存配置执行，提示说明实际执行的是已保存配置而非屏幕所见

#### Scenario: 执行期耗时预期
- **WHEN** 立即备份请求进行中
- **THEN** 按钮锁定不可重复点击，等待文案包含启用位置数量与耗时预期

#### Scenario: 冲突拒绝可见
- **WHEN** 备份或恢复任务进行中触发立即备份返回 409
- **THEN** 展示「已有备份/恢复任务进行中」类明确提示，不静默失败

### Requirement: 位置健康信号与安全交互
备份位置表格 SHALL 展示每个位置的「最近推送」状态（状态点 + 最近推送时间，数据从备份历史的位置子结果聚合派生，删除位置后以名称快照参与聚合，不新增后端接口）与「最近测试」结果；位置测连文案 MUST 明示校验范围（仅 SSH 连通与凭据正确，不校验远端目录可写性与磁盘空间）；停用位置 MUST 经确认（提示将停止接收新备份、容灾能力下降）；位置启用开关 MUST 与全站控件风格一致。

#### Scenario: 最近推送状态点
- **WHEN** 某位置最近一次推送子结果为失败
- **THEN** 该位置行显示红色状态点，tooltip 显示最近推送时间与结果

#### Scenario: 删除位置的名称快照参与聚合
- **WHEN** 某位置被删除后查看其参与过的历史
- **THEN** 健康聚合仍按名称快照计算，不因位置删除而丢失信号

#### Scenario: 测连范围明示
- **WHEN** 用户点击位置「测试连接」
- **THEN** 提示或结果说明明确校验范围仅含 SSH 连通与凭据，不含远端目录可写性与磁盘空间

#### Scenario: 停用确认
- **WHEN** 用户关闭某启用位置的开关
- **THEN** 弹出确认（说明该位置将不再接收新备份、容灾能力下降），确认后方生效

### Requirement: 历史可读性与恢复打通
备份历史列表 SHALL 支持按状态与触发来源筛选；失败记录的失败原因 MUST 行内可见（展开或折叠区内，不依赖 hover title；构建阶段失败 MUST 同样有可展开的原因区）；每条含包名的历史记录 SHALL 提供「恢复此包」入口，仅在存在已配置备份位置时显示，点击后打开恢复向导并预选该包；手动输入来源路径不参与预选。

#### Scenario: 失败原因行内展开
- **WHEN** 历史列表存在失败记录（含构建阶段失败）
- **THEN** 行内提供展开操作，展开后直接可见失败原因，无需 hover

#### Scenario: 历史筛选
- **WHEN** 用户按状态「失败」或触发来源「手动」筛选
- **THEN** 列表仅显示匹配记录，筛选与分页组合正确

#### Scenario: 从历史发起恢复
- **WHEN** 已配置备份位置且用户点击某成功历史记录的「恢复此包」
- **THEN** 恢复向导打开并预选该包（高亮/勾选状态可见），用户从校验步骤继续

### Requirement: 摘要卡口径与入口样式对齐
数据库管理页备份摘要卡 SHALL 与主卡口径一致：下一轮显示具体时间（无计划时显示「未启用定时」）、备份进行中显示进行中状态、状态徽章全部为中文（含 running 态）；摘要卡与主卡上的「灾难恢复 / 恢复向导」入口 MUST 为次级样式（非危险描边常驻态），执行恢复的高危视觉仅保留在实际执行步骤内。

#### Scenario: 摘要卡显示具体下一轮时间
- **WHEN** 定时备份已启用且 status 返回 next_run_at
- **THEN** 摘要卡显示与主卡一致的具体时间，而非「间隔 N 分钟」

#### Scenario: 摘要卡进行中状态
- **WHEN** 备份任务执行中
- **THEN** 摘要卡显示「备份中」进行中状态（中文徽章），不显示英文原文

#### Scenario: 危险入口降级
- **WHEN** 用户浏览备份页与数据库管理页常态界面
- **THEN** 恢复类入口为次级按钮样式，无危险色描边常驻
