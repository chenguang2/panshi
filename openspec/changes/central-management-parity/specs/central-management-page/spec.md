# central-management-page 变更规格

## ADDED Requirements

### Requirement: 统一管理页网格态与卡片页标准同构

统一管理页的卡片网格态 SHALL 与全站卡片页标准同构（#85/#86/#88）：工具条、状态 chips 行、卡片网格同处单一面板框（l5-card）内。

#### Scenario: 单面板包含

- **WHEN** 页面处于网格态渲染集群列表
- **THEN** 工具条行、状态 chips 行、卡片网格位于同一个带边框圆角的面板（`.l5-card`）内
- **THEN** 卡片网格自身不另带面板边框，网格与面板内缘之间留有 16px 内距

#### Scenario: 工具条控件集

- **WHEN** 渲染网格态工具条
- **THEN** 工具条含搜索框（宽 150，占位「搜索集群名称或显示名...」）与「全部分组」下拉（宽 104）
- **THEN** 分组模式下工具条含「全部收起/全部展开」单按钮（平铺模式隐藏）
- **THEN** 工具条右端为「分组 | 平铺」模式切换段
- **THEN** 工具条不显示「共 N 个集群」计数（总数由状态 chips「全部 N」承担）

#### Scenario: 状态筛选为带计数 chips

- **WHEN** 渲染状态行
- **THEN** 显示「全部 N / 已启用 N / 已禁用 N」三枚带计数 chips，点击即按启用位筛选列表
- **THEN** 页面不提供「全部状态」下拉（旧形态退场）

#### Scenario: 分组视图带集群分组带

- **WHEN** 分组模式渲染集群分组
- **THEN** 每组一条跨全宽分组带：组名 + 「N 个集群」计数 + 组内聚合次要指标「节点 N · 路由 N」+ 折叠控制
- **THEN** 整条分组带可点击折叠/展开，折叠控制与带本体不双重触发
- **THEN** 未分组集群置顶显示

#### Scenario: 平铺视图卡片即身份

- **WHEN** 切换到平铺模式
- **THEN** 分组带隐藏，全部集群卡按网格直接排布，卡片本体承载集群身份（名称/标识/色相）

#### Scenario: 页头补充维度徽标

- **WHEN** 渲染页头
- **THEN** 标题旁显示「N 集群」accent 徽标与「M 节点」弱化徽标（补充维度，非总数重复）

#### Scenario: 旧外壳不残留

- **WHEN** 网格态渲染
- **THEN** 旧工具条壳（状态下拉、「共 N 个集群」文本、全部展开/收起双按钮）不出现
- **THEN** 分组头内不再渲染可点击集群名小条（cluster-name-item 快捷入口退场；最大化入口为统计格与卡片标题栏「最大化」按钮）

### Requirement: 网格态与最大化面板两态模型

统一管理页 SHALL 只有两种呈现形态：卡片网格态与单集群最大化面板；不存在中间展开态。

#### Scenario: 统计格直达最大化

- **WHEN** 网格态点击集群卡上任意统计格（如「上游 N」）
- **THEN** 该集群立即最大化（网格收起、面板接管页面空间）并直达统计格对应的 Tab

#### Scenario: 卡片标题栏最大化按钮

- **WHEN** 点击集群卡标题栏「最大化」按钮
- **THEN** 该集群立即最大化并停留在默认 Tab（集群节点）

#### Scenario: 同屏单集群

- **WHEN** 任一集群处于最大化态
- **THEN** 页面仅呈现该集群的面板，其他集群不可同屏展开

#### Scenario: 紧凑栏切换保留 Tab

- **WHEN** 最大化态顶部紧凑栏展示全部集群条目（状态点 + 名称，当前项高亮）
- **AND** 用户点击另一集群条目
- **THEN** 原地切换到该集群最大化，且保持当前所在 Tab 不变

#### Scenario: 收起返回网格

- **WHEN** 点击「收起/退出最大化」
- **THEN** 返回网格态，搜索/分组/状态筛选条件保持
- **AND** 分组折叠态遵循既有行为（最大化动作折叠全部分组，收起后保持折叠，可经「全部展开」恢复）

### Requirement: 最大化面板解剖与 Tab 作用域

最大化面板 SHALL 按设计基线（central.html 状态二）呈现：集群色相容器、名称行、七 Tab 页签条与该集群作用域的资源管理面。

#### Scenario: 面板名称行

- **WHEN** 集群处于最大化态
- **THEN** 面板名称行显示集群显示名 + 标识 + 中继徽章（如挂接区域），右侧提供 详情 / 连接测试 / 编辑 / 导出 Excel / 备份下载 / 删除 动作行

#### Scenario: 七 Tab 页签与计数

- **WHEN** 渲染最大化面板页签条
- **THEN** 页签依次为 集群节点 / 上游 / 路由 / 插件组 / 插件元数据 / 全局规则 / 静态资源，每枚带资源计数徽标
- **AND** 权限不足的资源类型页签隐藏（沿用既有权限门控）

#### Scenario: Tab 为该集群作用域资源管理面

- **WHEN** 切换到任一 Tab
- **THEN** Tab 内为该集群作用域的资源列表，支持既有全部行内操作（新增/编辑/删除/发布/版本/差异/⋯ 菜单）
- **AND** 发布成功后的列表刷新沿用面板局部刷新（不整页重载、其他 Tab 已加载数据不丢失）

#### Scenario: 面板集群色相

- **WHEN** 集群处于最大化态
- **THEN** 面板容器携带该集群的色相（与卡片、分组带同源）

### Requirement: 集群管理功能面保持

统一管理页改版 SHALL 不改变任何集群管理功能语义。

#### Scenario: 集群 CRUD 与保存刷新

- **WHEN** 新建/编辑/删除集群（含备份下载、从备份导入）
- **THEN** 交互流程与既有实现一致（同一共享组件与编排）
- **AND** 编辑保存后列表自动重载（保存 → saved → loadClusters 链路保持）

#### Scenario: 连接测试与漂移检测入口保持

- **WHEN** 从卡片动作行发起连接测试 / 漂移检测
- **THEN** 弹窗/抽屉交互与结果呈现与改版前一致
