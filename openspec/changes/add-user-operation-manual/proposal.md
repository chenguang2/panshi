# 提案：新增「从零搭建」用户操作手册（docs/new）

## Why

现有 `docs/user-manual.md`（v1.19.0）是按功能模块罗列的参考型手册，存在两个不足：

1. **缺少端到端主线**：新用户面对空系统时，不知道应该先建什么后建什么。网关后台的正确上手顺序（集群 → 节点 → edge.env → 全局规则 → 插件元数据 → 插件组 → 上游 → 路由 → 证书 → 四层代理 → DNS 代理 → 域名验证）散落在各章节中，没有一条完整的实操路径。
2. **缺少选项级解释**：表单中每个字段"是什么、为什么填、填错会怎样"没有系统讲解，用户只能靠猜测。

需要一本以"从一个空系统开始，完整搭建一套可用网关"为主线的场景式操作手册，参考主流网关管理台（APISIX Dashboard / Kong Manager）的 Quickstart + 场景指南风格，让用户照着做即可得到一套能跑通 HTTP(HTTPS)/TCP/UDP/DNS 的演示系统。

## What Changes

- 新增 `docs/new/` 文档目录，存放新版操作手册（Markdown，含截图占位）
- 手册以**演示环境**贯穿全程：
  - 起点为干净的本地 SQLite 空库（通过数据库管理切换到空文件，重启后端生效）
  - 访问地址 `http://localhost:12345/`，默认账号 admin / panshi123
  - 3 个节点 192.168.0.13 / 14 / 15（机器上已预装 OpenResty/Edge 软件，属系统级前提；空库中平台无任何记录，需按第 2 章重新录入），OpenResty 路径 `/work/jboss/uapm/openresty`，Edge 路径 `/work/jboss/uapm/uap-edge`
- 章节顺序（每章统一结构：**本步骤的作用 → 入口 → 字段/选项逐项解释 → 操作步骤 → 发布 → 预期结果与验证方法**）：

|---|---|---|

## Impact

- **新增文件**：`docs/new/` 下两篇共 23 个章节文件（00-22，每章独立 .md）+ `README.md` 总目录（含两篇导航）+ `docs/new/images/` 截图
- **代码影响**：无（不修改前后端代码）
- **环境操作**：编写过程中需将后端切到空 SQLite 文件（如 `data/manual-demo.db`）截图，完成后恢复原数据库配置；第 21 章数据导入练习使用独立空库，避免污染演示库
- **旧文档**：`docs/user-manual.md` 本次不动；手册稳定后再决定是否替换或归档
- **风险**：低。唯一注意点是演示库切换/恢复期间不要污染现有开发数据
