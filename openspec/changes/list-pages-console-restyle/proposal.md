# Proposal

## Why

左侧菜单的节点管理、上游管理、路由管理三个独立列表页界面观感差：工具条元素堆叠无层次、状态标识不统一、操作列拥挤、页头零上下文、表格缺乏领域结构感。用户要求参考主流后台管理平台（Ant Design Pro 等）在**现有配色与整体风格不变**的前提下美化，并经多轮评审收敛为「方案 C · 网关控制台感」定稿（视觉规格见 `docs/ui/Live-Artifact-5/proposal-c/`，评审裁决记录见该目录 README）。

## What Changes

- **三页集群分组**：表格按集群分组（组头 = accent 条 + 集群名 + 组内统计芯片 + 可折叠），「所属集群」列随之移除；分组为页内聚合（当页按 集群→组内序 排序后聚组，翻页组聚散；按集群整组分页留作后续增强，不在本轮范围）。
- **显式双模式**：工具条右端新增「分组 | 平铺」切换器（默认分组）。平铺模式 = 现有表格行为（无组头）；分组模式下表头点击不排序并弹一次性提示引导切平铺；排序键跨模式保留（分组期间休眠、回平铺原样恢复）；筛选跨模式永久保留；无命中行的集群组不显示（不出空组）。
- **页头轻统计徽标**：三页页头标题右侧加全局口径统计徽标（如节点页 `27 节点 · 21 运行中 · 2 未检测`），与组头的组内统计形成总分关系；数据来自列表接口客户端聚合，无新接口。B 方案的 KPI 统计卡已被用户否决（三层重复 + 高度成本），不落地。
- **路由页**：工具条定为 V2 双行（方法 chips 附属行紧贴表头上方 + 纯筛选行）；列改 L2 全独立（优先级 mono 徽章、上游 chip、无集群列），方法 + URI 合并「请求匹配」列（呈现层合并，列配置仍为独立字段）。
- **上游页**：目标节点列升级为「目标节点与健康」（健康点 + 权重占比条 + 权重·百分比 + 健康汇总行）。
- **节点页**：Edge / OpenResty 安装路径两列合并为「安装路径」单列两行堆叠（`Edge`/`OR` 小标签）。
- **状态语言统一**：运行态/发布状态统一胶囊 + 圆点语言（发布状态含差异预览圆形按钮，四态判定口径不变）；「⋯」更多菜单改两行式条目（主文案 + 灰色解释、危险项红色），与 `ux-action-menu-explanations` 语言一致。
- **工具条右端统一**：`…筛选控件 → 计数 → 刷新 → 列配置 → 分组|平铺切换器（最右）`；**上游/路由新增刷新按钮**（语义与节点页一致 = 重新拉取列表，路由页此前规格已承诺、本次落地）；路由页计数保留在方法 chips 行右端（V2 结构）。
- **批量条与分页**：批量条选中态 accent 强调（新增「清除选择」右置）；分页规范化（左「共 N · 每页选择」、右页码 + 快速跳页）。
- 全部功能零删减：筛选项、列集合（列配置）、行内动作与「更多」菜单项、批量动作集、发布/删除/版本入口全部保留；列配置/拖拽调宽调序/序号列恒展示等既有能力不变。

## Capabilities

### New Capabilities

- `list-page-cluster-grouping`: 三个独立列表页的集群分组呈现与显式双模式交互——组头结构、组内统计芯片、折叠记忆、页内分组语义、分组/平铺切换器、模式间筛选与排序键语义、空组不显示。
- `list-page-header-stats`: 三个独立列表页页头轻统计徽标——全局口径统计、客户端聚合数据来源、与组头统计的总分关系。

### Modified Capabilities

- `table-toolbar-ux`: 「独立列表页工具条右端形态」——列配置触发按钮位置由「紧邻筛选控件（靠左）」改为右端统一簇（计数 → 刷新 → 列配置 → 切换器最右），反转既有「不得推到工具条右端」规则；上游/路由新增刷新按钮；路由页计数移至方法 chips 行右端。
- `table-sorting`: 排序可用性按视图模式限定——排序仅在平铺模式生效（路由四列服务端排序不变），分组模式表头点击给引导提示，排序键跨模式保留；节点/上游两页维持无排序现状。
- `node-management`: 「表格列定义」——移除「所属集群」列（由集群分组呈现替代），Edge 路径与 OpenResty 路径合并为「安装路径」单列两行堆叠。

## Impact

- **前端（全部改动所在）**：`frontend/src/views/NodeList.vue`、`UpstreamList.vue`、`RouteList.vue` 及其共享依赖（`composables/useClusterUtils.ts` 发布/删除进度、`components/ColumnConfigPopover.vue`、`useColumnDragColumns`、`usePagination`、`PublishStatusTag` 等）；可能新增共享组件（集群分组表头、模式切换器、页头统计徽标、状态胶囊）。
- **后端**：零接口改动（分组为前端页内聚合，徽标为客户端统计；刷新复用既有列表端点）。
- **不受影响**：统一管理页三张 Tab 子表（ClusterNodes/ClusterUpstreams/ClusterRoutes）、列配置存储键（`*_standalone` 与 Tab 键继续分立）、其余资源页面。
- **守卫与既有测试**：`tableAnatomy.source.test.ts`（序号列）、`SearchInput` 源码守卫、`tableToolbarUx`/列配置相关测试、权限键测试需保持或同步更新；共享组件语义变更按约定 #217 先 grep 消费方与既有断言，产断言反转清单后全量单测收口。
