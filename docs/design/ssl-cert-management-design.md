# 证书管理分组重构设计（SSL 证书 → 证书管理）

> 状态：待评审（设计蓝图 + HTML 示例页）
> 日期：2026-10-22
> 示例页：`/tmp/opencode/ssl-cert-mockup.html`（自包含，浏览器直接打开）

## 1. 背景与问题

运维经常把「服务器证书」发给内部系统的用户安装，导致两类事故：

1. **显示不安全**：服务器证书不是信任锚点，终端系统必须安装的是签发它的 **CA 根证书**；
2. **私钥扩散**：当前下载弹窗默认勾选私钥（key.pem），随 zip 一起发给用户，属敏感数据泄露。

根因是入口不区分语义：CA 根证书与服务器证书混在 `/ssl` 一个页面里，只靠页内 Tab 区分；
下载弹窗对两类证书都提供 cert.pem + key.pem，格式后缀 `.pem` 在 Windows 上双击无法安装。

现状盘点（探索结论）：

- 后端 `SslCertificate` 已有 `is_ca` / `ca_cert_id` 字段，CA 按集群存储（`POST /clusters/{id}/ssl/ca` 生成）；
- 生成服务器证书已强制要求选 CA（`ca_cert_id`），签发链路完整，**无需改后端模型**；
- 私钥已有按需端点 `GET /clusters/{id}/ssl/{cert_id}/key`（高风险、审计），「查看」抽屉内已有确认弹窗流程；
- 下载统一走 `SslCertDownloadDialog` → `buildCertZip`（`{name}_cert.pem` / `{name}_key.pem` 打包 zip）；
- 侧边栏为「分组（可折叠）+ 菜单项」两级结构，`ssl_cert` 是权限与 feature 复用键；
- `featureRouteMap` 已有多路由挂同一 feature 键的先例（`metrics` 挂 `/metrics` 与 `/metrics/dashboard`）。

## 2. 目标 / 非目标

**目标**

1. 侧边栏新增顶级分组「证书管理」，下设「CA 根证书」「服务器证书」两个子菜单；
2. 两类证书页面语义分离：CA 根证书页明确「可下载给用户」；服务器证书页明确「用户需下载 CA 根证书、服务器证书变更后已下载副本即失效」；
3. 下载产物改为用户可直接安装的格式：`.crt` 后缀（PEM 内容）；**下载链路不再提供任何私钥**；
4. 私钥获取收敛到「查看」抽屉（既有高风险确认 + 审计流程），列表/弹窗不出现。

**非目标**

- 不改后端数据模型与签发/发布/版本回滚逻辑（CA 拼链发布、生成强制选 CA 均保持现状）；
- 不做证书到期自动轮换、自动重新分发通知（后续独立立项）；
- 不动国密双证书签发语义。

## 3. 信息架构

```
侧边栏
├── 核心功能（不变）
├── 证书管理                        ← 新增分组
│   ├── CA 根证书    → /ssl/ca      ← 新视图 CaCertList.vue
│   └── 服务器证书   → /ssl/server  ← 新视图 ServerCertList.vue
├── 边缘网络（不变）
└── …
```

- 路由：`featureRouteMap` 的 `ssl_cert` 键下挂两条路由（仿 `metrics` 先例）；
  旧 `/ssl` 保留为 redirect → `/ssl/server`（兼容旧链接与收藏，零成本）。
- 权限/feature：沿用既有 `ssl_cert` 权限键与 `features.yaml` 的 `ssl_cert` 开关，不新增权限键（四层接线中 ①③④ 层零改动，② 层拆两条路由）。
- 组件拆分：`SslList.vue` 拆为两个视图页；证书卡片、下载弹窗抽成共享组件（`SslCertCard.vue` / 新下载弹窗），两页复用，避免第三份内联实现（约定 #51 教训）。
- 分组位置：建议放「核心功能」之后、「边缘网络」之前（证书属集群配置域，使用频率低于集群/路由、高于边缘网络工具）。

## 4. 页面设计

### 4.1 CA 根证书页（/ssl/ca）

```
┌──────────────────────────────────────────────────────────────┐
│ PageHeader: CA 根证书        [+ 创建 CA 根证书]               │
├──────────────────────────────────────────────────────────────┤
│ ✅ 信息横幅（常驻，绿色系）：                                 │
│ 「CA 根证书可以放心分发给最终用户——它不含私钥，               │
│   是让各系统显示『安全』的唯一正确选择。」                     │
│   [下载分发给用户 ↓]（滚动到列表） [查看安装指引]              │
├──────────────────────────────────────────────────────────────┤
│ 筛选行：搜索 / 集群分组 / 集群 / 共 N 个                      │
│ ┌─────────────┐ ┌─────────────┐                              │
│ │ CA 卡片      │ │ CA 卡片      │   每卡片：                   │
│ │ 主操作：     │ │              │   - 集群顶栏 + 算法徽章      │
│ │ ⬇ 下载根证书 │ │              │   - CN / 算法 / 有效期徽章   │
│ │   (.crt)    │ │              │   - [查看] [⬇下载根证书.crt] │
│ └─────────────┘ └─────────────┘     [删除]                   │
└──────────────────────────────────────────────────────────────┘
```

- **下载行为（单文件直下）**：`downloadPem(ca.cert, '{集群名}_{名称}.crt')`，
  `application/x-x509-ca-cert`，不走 zip、无任何私钥选项。PEM 内容 + `.crt` 后缀
  在 Windows（双击进安装向导）/ macOS（钥匙串）/ Linux（ca-certificates）均可用。
- **查看抽屉**：保留既有 CA 详情 + 「下载 CA 私钥」高风险确认（审计），文案补一句
  「私钥仅用于签发证书，绝不可分发给用户」。
- **安装指引**（改进项 E1）：横幅内折叠面板，给出 Windows / macOS / Chrome / Linux
  四段一步一击的安装步骤（正文文案，评审时定稿）。
  Chrome 段介绍**在 Chrome 浏览器内安装**：设置 → 隐私与安全 → 安全 → 管理证书 →
  「证书颁发机构」导入 `.crt` 并勾选信任（Windows 下引导至系统导入向导，
  Linux 下导入 Chrome 自身的 NSS 证书库），不介绍 Firefox。
- **过期提醒**（改进项 E4）：CA 卡片到期徽章沿用现有 expire badge，但 CA 过期意味着
  所有已分发终端全部失效——≤30 天时徽章升级为红色 + 卡片顶部警示条，提示重新分发。

### 4.2 服务器证书页（/ssl/server）

```
┌──────────────────────────────────────────────────────────────┐
│ PageHeader: 服务器证书     [+ 添加已有证书] [生成证书]         │
├──────────────────────────────────────────────────────────────┤
│ ⚠️ 警示横幅（常驻，琥珀色）：                                  │
│ 「请勿将服务器证书分发给终端用户——它不是信任锚点，             │
│   且证书更新后旧副本即失效。用户系统应安装 CA 根证书。」        │
│   [前往 CA 根证书下载 →]（跳 /ssl/ca）                        │
├──────────────────────────────────────────────────────────────┤
│ 筛选行（同现有：搜索/分组/集群/计数）                          │
│ 服务器证书卡片网格（沿用现有卡片：SNI/类型/算法/协议/有效期/   │
│ 发布状态标签/发布/版本管理），新增一行：                       │
│   签发 CA: {ca_name}（可点击 → 跳转 CA 页并定位）  ← 改进 E3  │
└──────────────────────────────────────────────────────────────┘
```

- **下载弹窗重做**（替换 `SslCertDownloadDialog`）：

```
┌─ 下载服务器证书 ─────────────────────────── ✕ ─┐
│ 证书：xxx（国密 SM2 双证书）                    │
│ ☑ 服务器证书 xxx.crt                           │
│ ☑ 签名证书 xxx_sign.crt        ← 仅国密出现    │
│                                                │
│ ┌────────────────────────────────────────────┐ │
│ │ ⚠ 此文件是当前版本的副本：证书更新或重新    │ │
│ │ 生成后即失效，届时需重新下载分发。          │ │
│ │ 终端用户请安装 CA 根证书 → [下载 CA 根证书] │ │
│ └────────────────────────────────────────────┘ │
│ ⓘ 私钥不随证书下载：仅平台发布部署使用，        │
│   如需查看请在「查看」抽屉中操作（高风险、审计） │
│                                                │
│                    [取消]  [下载 .crt]          │
└────────────────────────────────────────────────┘
```

  - 不再提供 key 选项（后端 `/key` 端点保留，仅查看抽屉入口）；
  - 单证书：直接下载单个 `.crt`（`{名称}.crt`），不再打 zip；
  - 国密双证书：打 zip（`{名称}_certs.zip`，内含 `xxx.crt` + `xxx_sign.crt`，无 key）;
  - 下载成功 toast 追加提示（改进 E2）：「已下载。证书更新后此副本即失效，请勿分发给终端用户」。

## 5. 下载规格总表

| 资源 | 产物 | 后缀 | 内容 | 形态 | 私钥 |
|---|---|---|---|---|---|
| CA 根证书 | `{集群}_{名称}.crt` | `.crt` | CA PEM | 单文件直下 | ❌ 永不 |
| 服务器证书（国际） | `{名称}.crt` | `.crt` | 服务器证书 PEM | 单文件直下 | ❌ 永不 |
| 服务器证书（国密） | `{名称}_certs.zip` | `.zip` | 加密 `.crt` + 签名 `.crt` | zip | ❌ 永不 |
| 私钥（任何类型） | — | — | — | 仅查看抽屉按需 | 审计 |

## 7. 待拍板决策点（均有推荐项）

| # | 决策 | 推荐 |
|---|---|---|
| 1 | 旧路由 `/ssl` | redirect → `/ssl/server`（兼容旧链接） |
| 2 | 「证书管理」分组位置 | 核心功能之后、边缘网络之前 |
