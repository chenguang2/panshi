# 3. 统一管理

> 本章场景：「统一管理」以**集群为单位**把资源统计、监控与运维入口聚合到一个页面——每个卡片是一个集群的"驾驶舱"，适合多集群环境的日常巡检与快速跳转。

## 3.1 页面入口

点击左侧侧边栏：【核心功能】→【统一管理】。


> 若菜单不可见：回[第 1 章 功能开关前置检查](01-login.md)核对权限配置。

## 3.2 界面结构

### 3.2.1 集群分组

集群按「分组」字段归类显示（第 4 章创建集群时的分组），支持：

- **全部展开 / 全部收起**：一键控制所有分组的折叠状态；
- 单个分组标题可点击折叠/展开；
- **未分组组头固定在第一行**（与集群管理一致）——新建/待归组集群第一时间可见，可直接拖拽进目标分组。

### 3.2.2 集群卡片与资源统计

每个集群一行，核心是**资源统计格（7 格）**，点击直接跳转到对应管理页：

| 统计项 | 含义 | 点击行为 |
| --- | --- | --- |
| 节点 | `健康数 / 总数`（如 `3/3`） | 跳转节点管理（该集群） |
| 上游 | 该集群上游数量 | 跳转上游管理 |
| 路由 | 该集群路由数量 | 跳转路由管理 |
| 插件组 | 插件组数量 | 跳转插件组 |
| 全局规则 | 全局规则数量 | 跳转全局规则 |
| 插件元数据 | 插件元数据数量 | 跳转插件元数据 |
| 静态资源 | 静态资源数量 | 跳转静态资源 |

> 💡 节点格显示 `2/3` 说明有一台不健康——优先处理（排查见[15.3.4 发布失败排查](15-edge-env.md)）。

卡片大小与集群管理完全一致（3 列网格，窄窗口自动降 2 列/1 列）。

### 3.2.3 卡片操作区

【详情】/【连接测试】/【**漂移检测**】/【编辑】/【更多 ▾】（备份下载、导出 Excel）/【删除】——与集群管理卡片逐项一致；漂移检测详见[附录 E](E-drift-detection.md)。

### 3.2.4 最大化模式

点击卡片右上角的【最大化】图标，该集群进入全屏工作台：左侧切换节点/上游/路由等标签页，右侧为对应管理界面，免去页面间来回跳转。完成后点击【还原】(退出最大化) 返回列表。


## 3.3 与其他页面的关系

| 需求 | 推荐入口 |
| --- | --- |
| 看**流量指标**趋势 | 【指标总览】（第 19 章） |
| 管**单个集群**的全部资源 | 本页最大化模式，或【集群管理】 |
| 建/删集群、改分组 | 本页【+ 新建集群】，或【集群管理】 |

## 3.4 数据备份与恢复

统一管理页面提供三种数据管理能力，位于集群卡片操作区和页面顶部。

### 3.4.1 导出 Excel

点击集群卡片【更多 ▾】菜单中的【导出 Excel】，系统将该集群的全部资源（节点、上游、路由、插件组、全局规则等）导出为 Excel 文件并自动下载。

**Excel 包含的工作表**：

| 工作表 | 内容 |
| --- | --- |
| 集群 | 集群基本信息（名称、描述、分组、状态） |
| 节点 | 节点 IP、SSH 端口、服务端口、健康状态 |
| 上游 | 上游名称、目标地址、协议、负载均衡方式 |
| 路由 | 路由 URI、方法、上游绑定、插件组 |
| 插件组 | 插件组名称及包含的插件列表 |
| 全局规则 | 限流、CORS、IP 黑白名单等全局规则 |
| SSL 证书 | 证书域名、颁发者、过期时间（不含私钥） |
| 静态资源 | 资源名称、绑定路由、文件大小 |
| 四层代理 | TCP/UDP 代理规则 |
| 插件元数据 | 自定义插件定义 |

> ⚠️ Excel 是**人读报表**，不含加密凭据和文件本体，不能用于程序化恢复。需要完整备份请使用【备份下载】。

### 3.4.2 备份下载


点击集群卡片【更多 ▾】菜单中的【备份下载】，系统弹出备份对话框：

1. 可选勾选「包含敏感信息」（admin_key、SSH 密码等加密字段）
2. 可选勾选「包含文件内容」（静态资源文件的 base64 编码）
3. 点击【下载备份】，系统生成 JSON 格式的完整备份文件并自动下载

**备份文件格式**：`{集群名}_backup_{日期}.json`，包含：

- 集群、节点、SSL 证书、上游、路由、插件配置、全局规则、插件元数据、四层代理、静态资源
- 元数据：版本号、导出时间、SHA-256 校验和

> 💡 备份文件可用于跨环境迁移或灾难恢复。



### 3.4.3 从备份导入


点击页面顶部的【从备份导入】按钮：

1. 选择备份 JSON 文件
2. 输入目标集群名称（不能与现有集群重名）
3. 系统校验备份格式后创建新集群（状态为「未发布」）
4. 导入完成后需手动发布才能推送到 Edge 节点

**导入行为**：

- 所有平台自增 ID 重新分配，不影响现有数据（clone-only 单向语义，不保号）
- 外键关系自动重建（节点→路由→上游等）
- 敏感信息（如未勾选包含）使用空占位，发布前需补充
- 整个导入在一个事务内完成，中途失败自动回滚

## 3.5 本章小结

- 统一管理 = 多集群驾驶舱：分组浏览（未分组置顶）+ 7 格资源统计直跳 + 一键跳转
- 节点健康比 `x/y` 是巡检第一信号
- 最大化模式 = 单集群全屏工作台，多标签免跳转
- Excel 导出 = 人读报表，备份下载 = 完整备份，从备份导入 = 新建集群（clone-only）
- 卡片操作与集群管理逐项一致，含漂移检测（附录 A）
