# 24. 工具箱

> 运维管理入口——【工具箱】是日常开发调试的瑞士军刀，全部为纯本地转换，输入不出本机。

## 24.1 页面入口

点击左侧侧边栏：【运维管理】→【工具箱】。


> 若菜单不可见：回[第 1 章 功能开关前置检查](01-login.md)核对 `tools` 开关。

## 24.2 内置工具

左侧图标列表切换工具（共 **13 件**），全部为**纯本地转换**（输入不出本机）：

| 工具 | 用途 |
| --- | --- |
| Lua 互转 | Lua 代码片段格式化/处理，配合路由自定义预处理插件（第 7 章）使用 |
| URL 编解码 | URL 编码与解码互转 |
| JSON 格式化 | JSON 压缩/美化，排查接口返回时常用 |
| SM4 加解密 | 国密 SM4 加解密计算，配合国密证书场景（第 13~14 章） |
| Base64 编解码 | Base64 编码/解码（配置脚本管道传输常用） |
| YAML 格式化 | YAML 压缩/美化 |
| YAML↔JSON 互转 | YAML 与 JSON 双向转换 |
| JSON 对比 | 两份 JSON 结构化差异对比 |
| 文本 Diff | 纯文本差异对比 |
| 时间戳转换 | Unix 时间戳与可读时间互转 |
| JWT 解码 | 解析 JWT 三段结构查看载荷（不解签） |
| 哈希计算 | 常见摘要算法计算（MD5/SHA 族） |
| IPv4/CIDR 计算器 | 子网掩码/网段范围计算，录入节点与白名单时常用 |

每个输入/输出框都带【复制】/【粘贴】按钮。


## 24.3 本章小结

- 工具箱 = 本地转换十三件套，数据不出本机
- 网关场景高频：Lua 互转（预处理插件）、Base64（脚本管道）、IPv4/CIDR（节点/白名单录入）
