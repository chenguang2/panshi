# 附录 B：修改 DNS（Windows）

> 适用场景：内网部署了 DNS 服务器并托管了网关域名（如 `test.com`）时，将客户端的首选 DNS
> 指向内网 DNS 服务器，使域名统一解析到网关 IP。相比逐台修改 hosts（附录 A），DNS 方式只需维护一份解析记录。
>
> 演示环境约定：内网 DNS 服务器地址以 `10.158.40.77` 为例（请向网络管理员获取实际地址），
> 网关域名 `test.com` 解析到 `192.168.0.13`。

### 🟢 一、Windows 10 / Windows 11 修改 DNS

**方法 1：通过"设置"应用（最快捷）**

1. 按下 `Win + I` 快捷键打开"设置"，点击"网络和 Internet"。
2. 根据当前连接方式，点击左侧的"WLAN"或"以太网"，然后点击当前正在连接的网络名称。
3. 找到"DNS 服务器分配"选项，点击旁边的"编辑"按钮。
4. 将"自动(DHCP)"更改为"手动"，打开"IPv4"开关。
5. 在"首选 DNS"框中输入内网 DNS 服务器地址（如 `10.158.40.77`），点击"保存"。

**方法 2：通过传统控制面板**

1. 按 `Win + R` 键，输入 `ncpa.cpl` 并回车，打开"网络连接"窗口。
2. 右键点击正在使用的网络适配器，选择"属性"。
3. 双击"Internet 协议版本 4 (TCP/IPv4)"。
4. 选择"使用下面的 DNS 服务器地址"，在"首选"中填入内网 DNS 服务器地址，点击"确定"保存。

---

### 🟡 二、Windows 8 / 8.1 修改 DNS

1. 在屏幕右下角找到网络连接图标，右键点击选择"打开网络和共享中心"。
2. 在左侧菜单中点击"更改适配器设置"。
3. 找到当前正在使用的网络连接（如"以太网"或"WLAN"），右键点击并选择"属性"。
4. 在列表中找到并双击"Internet 协议版本 4 (TCP/IPv4)"。
5. 选择"使用下面的 DNS 服务器地址"，在"首选 DNS 服务器"栏中输入内网 DNS 服务器地址。
6. 依次点击"确定"保存设置并关闭所有窗口。

---

### 三、Windows 7 修改 DNS

1. 点击左下角的"开始"按钮，打开"控制面板"。
2. 进入"网络和 Internet" -> "网络和共享中心"。
3. 在左侧点击"更改适配器设置"。
4. 右键点击当前正在使用的网络连接，选择"属性"。
5. 双击"Internet 协议版本 4 (TCP/IPv4)"。
6. 勾选"使用下面的 DNS 服务器地址"，在"首选 DNS 服务器"中输入内网 DNS 服务器地址。
7. 点击"确定"保存并关闭所有窗口。

---

### 四、全局通用：刷新缓存与验证（所有 Windows 版本适用）

无论使用的是哪个版本的 Windows，修改完 DNS 后，都建议执行以下两步以确保配置立即生效：

**1. 刷新本地 DNS 缓存**

按 `Win + R` 输入 `cmd` 打开命令提示符，执行：

```cmd
ipconfig /flushdns
```

*(看到"已成功刷新 DNS 解析缓存"即表示成功)*

**2. 验证 DNS 是否生效**

在同一个命令提示符窗口中执行：

```cmd
nslookup test.com
```

* **如何看结果**：观察返回信息中的 `Address` 字段，如果显示的 IP 是网关地址（如 `192.168.0.13`），则说明你的 DNS 服务器已经成功切换并且域名解析生效。

> 💡 如果 `nslookup` 返回的解析结果不正确，请检查：
> - 内网 DNS 服务器上是否已添加 `test.com -> 网关IP` 的 A 记录；
> - 本机是否还残留 hosts 映射（hosts 优先级高于 DNS，参见附录 A）。
