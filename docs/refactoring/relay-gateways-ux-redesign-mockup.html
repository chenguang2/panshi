中继区域管理

维护各局中继网关的注册信息：平台到该局的两条管理通道（发布走 HTTP 腿、安装任务走 SSH 腿）经网关机中转；未建区域的集群保持直连，不受影响。

i
哪些局需要建中继区域？—— 平台到局内网络不通、必须经网关机中转的局才需要建

平台到各局 Edge 节点有两条通道：发布配置走 HTTP 腿（网关机 8443 反向代理），安装与任务走 SSH 腿（经网关机跳板转发）。 区域建好并挂接到集群后，两条通道自动改经该局网关；没建区域的集群保持现状直连。网络本就互通的局不需要建，选「直连区域」即可。

① 登记区域 新建区域，填网关地址与账号 → ② 初始化网关 首次装机必做，写入 8443 监听 → ③ 下发配置 把节点白名单推送到网关机
📖 「初始化网关 / 下发配置 / 配置跳板转发」何时用哪个？（点开看对照）

🚀 初始化网关

何时用：首次装机、网关机重装 OpenResty 之后

  • 在网关机写入 8443 监听 server 块 + 当前节点白名单，校验后 reload
  • 幂等可重复执行，跑多次没有副作用
  • 要求已填 OpenResty 前缀

📤 下发配置

何时用：日常 —— 集群挂接区域、节点增删、节点启停之后

  • 只推节点白名单（全量替换），不动 8443 监听
  • 白名单为空时会弹危险确认（清空 = 全部 403）
  • 该局全部网关机都成功才算成功

🔐 配置跳板转发

何时用：仅跳板 SSH 部署，且网关机 sshd 默认禁止转发时

  • 用 root 在网关机放行 SSH 转发（PermitOpen 白名单）并重载 sshd
  • 一次配置即可，不改平台配置
  • 校验失败自动回滚，不影响正在运行的 sshd
常见症状 → 建议动作（体检结果里也会给出同样建议）
✗ HTTP 腿不可达 确认网关机 8443 服务已启动；首次装机先执行 「更多 ▾ → 初始化网关」
✗ SSH 腿不可达 核对 SSH 跳板地址与账号；若报 administratively prohibited，执行 「配置跳板转发」放行
「清单缺组」标签 该局主机组尚未写入网关清单，执行初始化/下发会先被拦截——先完成清单登记再操作
