不推荐

彻底解耦列宽问题，但违背你已确认的「待发布旁边小三角」交互设计；且 Tab 操作列已有 6 个按钮（复制/编辑/删除/发布/版本管理），再塞一个更挤。列出仅为完整性。

方案改动优点代价 / 风险
A（推荐） 四处列宽 → 200 + 状态单元格 nowrap 容器 改动最小；按钮任何状态下可见；不动文案不碰共享组件断言 状态列宽 60px（描述列有余量，见截图）；无
B partial 文案「发布未完全生效」→「未完全生效」+ 列宽 176 全站更窄更整齐；语义由 tooltip 承载 全站用户可见文案变更；#217 断言反转清单；列表上警示语义弱化一档
C 按钮挪操作列 彻底解耦 违背已确认交互设计；操作列更挤

推荐：A 直接落地（低风险先行）；B 若你认可「未完全生效」措辞可作为第二批文案优化叠加。回复如「A」或「A+B」即可。
