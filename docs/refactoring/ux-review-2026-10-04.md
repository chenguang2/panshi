# 磐石 Admin 全界面 UX/UI 评审报告

> 评审日期：2026-10-04 · 评审人：AI（GLM）· 委托：用户全界面四维评审（美观性/实用性/逻辑性/易用性）

## 评审方法与证据通道

- **素材**：2026-10-02 重制的手册截图产线（`docs/user-manual/images/`，180 张，含演示数据，已覆盖最新 UI 变更）
- **视觉取证**：zai OCR 服务端提取（布局分区级文本+视觉线索）；本环境模型不支持直接读图，`analyze_image` 通道超时不可用
- **实弹探针**：Playwright 直连运行中系统（localhost:12345）取真实 DOM 文本
- **代码取证**：模板/样式/交互流的全量代码知识（加载态/空态/键盘/响应式等截图不可见维度）
- **通道伪影声明（重要）**：OCR 会把部分中文 UI 文本规范成英文——「暂无数据」被读作 "No data"、「20 条/页」被读作 "20 / page"。两处均经 Playwright 实弹探针**推翻**（实况为中文），本报告不将其列为缺陷
- **覆盖**：侧边栏 5 分类 26 页 + 登录页 = 27 界面；中继区域管理因 feature 门控（演示环境关闭）无截图，按代码级评审

## 一、核心功能（10 页 + 登录）

### 【登录页】
- ✅ 做得好：①左右分栏品牌区+表单区，视觉聚焦明确；②密码可见性切换（眼睛图标）；③「记住我」与「忘记密码」辅助链接齐备
- ⚠️ 问题：「忘记密码?」半角问号混入中文文案（标点不规范）；无 Caps Lock 开启提示（大写锁定导致密码输错无反馈）；无用户名初始 autofocus（多敲一次 Tab）
- 💡 建议：标点统一全角「？」；密码框监听 `getModifierState('CapsLock')` 行内提示；`autofocus` 落到用户名框

### 【概览（Dashboard）】
- ✅：①九宫格统计卡信息密度得当，卡内趋势小图直观；②集群状态/节点在线/最近路由三表均带「查看全部→」逃生出口，符合下游深挖动线；③空态实测中文「暂无数据」（探针验证）
- ⚠️：统计卡数值无环比/趋势说明（如 QPS 较昨日），单点数值缺上下文；页面无初始焦点（探针 ACTIVE_EL=BODY）
- 💡：统计卡加同比箭头或 tooltip 说明口径；低优先级接受无焦点（管理后台惯例）

### 【集群管理】
- ✅：①分组卡片式列表 + 「全部收起」折叠，多集群可扫读；②卡片资源统计 7 项一览（节点/上游/路由/插件组/全局规则/插件元数据/静态资源）；③删除为红色危险样式，主次分明
- ⚠️：①「节点 0/0」实为 healthy/total（代码 `healthy_node_count/node_count`），**无 tooltip/图例**，新用户不可解；②新建集群表单含「状态」字段——创建即选运行状态违背心智模型（状态应是运行时属性，非创建参数）；③卡片四按钮（详情/编辑/连接测试/删除）视觉同级，无主操作强调
- 💡：①统计项加 title/悬浮说明「在线/总数」；②表单移除状态字段（默认正常，详情内可改）；③「详情」设为主按钮样式，其余降级

### 【节点管理】
- ✅：表格列含服务/管理端口、SSH 信息完整，连接形态（直连/中继）有徽章区分（中继功能上线后）
- ⚠️：①列头中英混排不统一：「服务端口」（中文）vs「EDGE安装路径」「OPENRESTY安装路径」（全大写英文+无空格）；②EDGE 版本未知时显示「-」，信息弱；③行操作收进「…」更多菜单，高频操作（如任务执行）多一跳
- 💡：①列头统一为「Edge 安装路径」大小写+空格规范；②版本空时显示「未采集」并可点击触发采集；③最高频 1-2 个操作提出来平铺

### 【上游管理】
- ✅：①搜索+分组/集群/算法三下拉筛选，筛选维度贴合使用；②列排序（名称/集群/负载均衡/目标节点/版本/创建时间）覆盖主排序需求；③分页实测中文（共 N 个上游·条/页·跳至）
- ⚠️：①版本未知渲染为「v--」（应显示「—」或「未发布」）；②目标节点徽章「192.168.0.13:8111（100）」括号权重语义靠猜，与四层代理页「ip:port:weight」冒号风格**不一致**
- 💡：①空版本显示「未发布」中性词；②全站统一权重表示法（建议 `ip:port · 权重100` 悬浮详情）

### 【路由管理】
- ✅：①HTTP 方法筛选按钮组（8 方法）+ 5 个下拉筛选，多维检索能力强；②方法徽章彩色区分请求类型
- ⚠️：①示例数据 9 个方法徽章全量平铺一行，视觉噪音大（真实数据会更长）；②URI「/\*」显示原始转义字符；③「优先级」纯数字列无排序语义说明（大者优先？）
- 💡：①方法>3 时收敛为「GET 等 5 种」+悬浮展开；②URI 渲染解码后的 `/*`；③列头加 title 或文档锚点说明优先级规则

### 【插件组 / 插件元数据 / 全局规则】（同款卡片模板，合并评审）
- ✅：①三页共用一套卡片布局（集群分组头+名称+状态徽章+描述+代码风格插件标签+双操作组），跨页一致性优秀；②「未发布」灰徽章/「已发布」+版本时间的状态语义统一（PublishStatusTag 组件复用）；③链接操作（查看/编辑/删除）与按钮操作（发布/版本管理）左右分区，操作分层清晰
- ⚠️：①卡片描述超两行截断，长描述不可展开看全；②插件标签无上限收敛（多插件卡片变高不等）
- 💡：①描述区加「展开/收起」或悬浮完整提示；②标签>4 收敛 +N

### 【静态资源】
- ✅：空态中文「暂无静态资源」规范；上传→路由分发的流程页职责单一
- ⚠️：空状态只有文字无引导 CTA（新建入口在右上，首次使用者视线不会先到那）
- 💡：空态中央加「上传第一个静态资源」主按钮（全站列表页空态统一此模式）

### 【SSL 证书】
- ✅：①Tab（全部证书/CA 根证书）folder 风格与备份页统一（近期视觉对齐成果）；②系统保留 SNI（edge.local 🔒）有明确标识；③证书类型/密钥信息（server·国际·RSA 2048·本地生成）徽章化
- ⚠️：①单卡片信息行拼接密度过高——「SNI：🔒edge.local（系统保留）｜ test.com」与「类型：server ｜ 🌐国际 RSA 2048 ｜ 本地生成」多义堆叠一行，扫读性差；②**列表卡片未见到期时间/临期预警**——证书管理的高价值信息缺位
- 💡：①信息分行结构化（SNI 行/类型行/来源行）；②加到期倒计时徽章（<30 天黄、<7 天红），列表按临期排序选项

## 二、边缘网络（4 页）

### 【edge.env 配置】
- ✅：①「分组→集群→节点」三级下拉定位 + Monaco 编辑器，远程配置工作台范式正确；②获取配置模板/发布/版本管理操作分区明确；③发布带 diff 预览与逐节点进度（流程截图链完整）
- ⚠️：初始态编辑器空白仅「行号 1」，无引导文案——新用户不知道下一步是「选集群→获取配置模板」还是直接可编辑
- 💡：空编辑器态叠加引导浮层/占位文案「请选择集群与节点，点击右上『获取配置模板』读取当前配置」

### 【四层代理】
- ✅：卡片命名「8880-服务转发」以监听端口打头，快速定位规则；协议/端口/负载均衡/后端节点信息完整
- ⚠️：后端节点「192.168.0.13:8111:100」三段冒号（ip:port:weight）与上游页「ip:port（weight）」风格不一致（同上游条目 ②）
- 💡：随上游页一并统一权重表示法

### 【DNS代理[UDP]】
- ✅：①卡片内嵌解析面板（域名/类型/TTL/后端节点）层次清楚；②「● 已发布 v2 · 时间」状态徽章与全站发布态语义一致
- ⚠️：TTL「TTL: 10s」中英混排小瑕疵（全站其余多为全角标点）
- 💡：统一为「TTL：10s」或徽章化

### 【DNS代理[HTTP]（页面标题「DNS 查询」）】
- ✅：空态「暂无 DNS 查询路由」中文规范；基于 dns_upstream 插件的职责描述清楚
- ⚠️：**菜单名「DNS代理[HTTP]」与页面标题「DNS 查询」术语漂移**——同一功能两个名字，导航心智断裂（用户点菜单找「代理」却落在「查询」）
- 💡：统一术语（建议菜单改「DNS 查询」或页面标题改「DNS 代理（HTTP）」），全站建立菜单↔页面标题一致性校验清单

## 三、综合（3 页）

### 【统一管理】
- ✅：①以集群为单位的聚合视图 + 「最大化」卡片展开，符合「按集群运维」心智；②资源统计 + 节点地址徽章列（● ip:port）一屏尽览；③「新建集群」主操作在位
- ⚠️：①**统计条末项被卡片右缘截断（截图可见「静」字切断）**——窄卡/中屏断点下统计 7 项一行放不下，响应式缺陷；②「节点 3/3」同集群管理页无图例问题；③分组头术语「未分组」vs 集群管理页「未分类」不一致；④操作行混入序号「#1」（与按钮同排，布局错位观感）
- 💡：①统计条改两行网格或允许换行+min-width；②③建全站术语表（未分类/未分组二选一）；④排查模板序号节点来源

### 【指标总览】
- ✅：①时间范围快捷组（1h/6h/24h/7d）+ 刷新间隔 + 自动开关，监控页标准件齐备；②图表占位「当前无数据」中文规范；③路由统计卡右上指标切换（QPS▾）
- ⚠️：①「加载中...」状态标签与图表占位并存时层级不清（首次加载体验）；②时间对比卡与状态码分析卡布局在窄屏下的降序未见保护（截断风险同统一管理）
- 💡：①加载态用骨架屏替代文字标签；②图表卡加 min-width/换行保护

### 【指标查询】
- ✅：①指标下拉带释义（`edge_http_latency_max — HTTP 最大延迟 (ms)`），专业指标可理解性做得好；②当前值+明细（读/写/等待/新建）双层数字呈现；③图例三线（平均/最大/最小）规范
- ⚠️：仅相对时间范围（1h~7d），无自定义起止时间——排障时常需定位特定时刻
- 💡：加「自定义」范围选项（datetime picker），或时间轴刷选

## 四、系统管理（8 页）

### 【插件开关】
- ✅：①分类 Tab（请求/响应重写/流量控制/数据处理/监控/静态资源）×搜索×状态筛选×计数×批量启用/禁用——工具链完整；②卡片信息结构好（名称/类别徽章/描述/代码标识/开关/schema 链接）；③旧版插件（functions_pre）标注兼容语义，避免误用
- ⚠️：开关切换后须滚到底部「保存配置」——列表长时保存按钮脱离视野，切完即走的修改会静默丢失
- 💡：有未保存修改时顶部吸附保存条或离开确认；开关行内即时保存提示

### 【数据库管理】
- ✅：①当前库卡片（类型徽章/名称/路径/在线点）+连接列表（测试/设为当前/编辑/删除）职责清晰；②「静态资源不受迁移/切换影响」信息提示消除高频误解；③当前连接的「设为当前」置灰防误操作
- ⚠️：①「+ 添加连接」双入口（页头+列表卡头）冗余；②本页内嵌「数据迁移」卡片与独立「数据迁移」菜单页并存——hub 摘要与专项页的关系对新手不直观
- 💡：①保留单入口（列表卡头）；②内嵌卡片标注「完整功能见『数据迁移』页 →」跳转链接（现有则强化可见性）

### 【数据迁移】
- ✅：①风险文案优秀——「迁移期间全局写暂停，请避开业务高峰」前置告知；②「我了解将清空目标库」确认门+开始迁移禁用态，破坏性操作双保险；③源→目标箭头可视化方向性，单向语义直白
- ⚠️：迁移模式仅「替换（清空目标库）」一种却用下拉呈现（若无其他模式应为固定说明文案）
- 💡：若模式唯一，改为醒目的静态警示块；下拉留给未来增量模式

### 【备份与容灾】
- ✅：①状态概览卡（最近成功/下轮预计/最近状态/调度）一屏判健康；②「立即备份」主按钮+「恢复数据…」红描边危险样式——危险层级正确（近期修复成果在档）；③folder Tab 三分区（备份位置/策略与保留/备份历史）与 SSL 页风格统一
- ⚠️：「从未备份」空态无行动引导（调度未启用是主要待办）
- 💡：空态卡内嵌「启用定时调度」/「立即备份一次」快捷链接

### 【审计日志】
- ✅：①四维修筛（用户/操作/资源/日期范围）+CSV/Excel 双导出+归档清理；②统计行「共 N 条 · 库内累计 N 条（最早 …）」给出数据全景口径；③详情列含变更摘要（「vars 从 '[]' 变更为 …」）——审计价值密度高
- ⚠️：详情长文本截断（「…None」），无悬浮全文/点击展开；操作类型（创建/更新/删除）徽章颜色区分未见
- 💡：详情单元格悬浮 tooltip 或行展开；操作动词三色徽章（绿/蓝/红）

### 【ClickHouse 配置】
- ✅：①「此处切换仅影响监控/指标数据源，与平台数据库无关」——范围澄清文案是全站范本；②当前连接卡+测试/设为当前，与数据库管理页同构
- ⚠️：①「+ 新建连接」双入口（页头+列表头）同数据库管理页；②连接名默认取 IP，与地址列信息重复，多连接时不可辨识
- 💡：①单入口；②新建时名称预填「指标库-1」类占位而非 IP

### 【用户管理】
- ✅：①角色徽章/权限/可访问集群列——RBAC 可视化完整；②搜索+角色/状态筛选+计数标准件
- ⚠️：操作全收进「⋯」更多菜单（编辑/重置密码等高频操作多一跳）
- 💡：最高频 1-2 项平铺

### 【中继区域管理】（feature 门控默认关闭，无演示截图，代码级评审）
- ✅：①区域/网关两级卡片（状态/前缀/HTTP 基址/ssh 跳板）；②初始化与下发配置走 SSE 流式进度（复用节点安装抽屉——长任务反馈模式全站一致）；③「清单缺组」漂移标记+配置预览只读兜底（ansible 不可用时手工配置）
- ⚠️：①网关注册不自动生成 inventory（手工维护+校验提醒为既定设计 D1），新手不知「注册后须手工补 [gateways_区域码] 组」；②功能开关（features.yaml）与菜单可见性的关系无页面内说明
- 💡：①网关保存成功后弹「需在清单补组」引导（同集群绑区域的 showRegionGuide 模式）；②开关关闭时菜单隐藏而非报错，文档注明开启路径
