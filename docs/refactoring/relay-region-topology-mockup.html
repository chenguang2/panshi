中继区域管理

维护各局中继网关注册信息：配置网关地址与 SSH 跳板后，该局节点的管理与数据通道将经由网关中转；未配置区域的集群按直连执行。

i
哪些局需要建中继区域？—— 局内网络与平台不互通时

中继区域 = 一台「跳板网关机」的登记信息。建好并挂接到集群后，该集群的发布/节点任务经它两条腿进局：HTTP 腿（管理请求走网关机 8443 反向代理）与 SSH 腿（安装/初始化类任务先跳到网关机再进局内）。局内网络本就互通的，不用建——不建或禁用都按直连执行。

「初始化网关 / 下发配置 / 配置跳板转发」，何时用哪个？（点击可收起）

🚀 初始化网关

何时用：首次装机、网关机重装 OpenResty 后

  • 写入 8443 监听 server 块 + 当前白名单
  • 校验后 reload，幂等可重复执行
  • 要求已填 OpenResty 前缀

📦 下发配置

何时用：集群挂接、节点增删、节点启停之后

  • 只推节点白名单（全量替换），不动 8443 监听
  • 幂等；空名单有危险确认
  • 不执行会被网关 403 拦截

🔑 配置跳板转发

何时用：跳板 SSH 部署且网关 sshd 默认禁转发时

  • root 写 sshd drop-in 放行 PermitOpen
  • 一次即可；格式不兼容自动降级
  • root 密码仅本次使用，不保存
常见症状 → 建议动作
HTTP 腿不可达 先执行 「更多 ▾ → 初始化网关」
SSH 腿报 administratively prohibited 执行 「配置跳板转发」 放行
状态列出现「清单缺组」 重新保存一次该区域（补齐 SSH 用户）即可重建清单组
