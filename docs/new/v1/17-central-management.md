# 17. 统一管理

> 本章场景：集群多了以后，在【集群管理】列表页逐个点进查看效率很低。「统一管理」以**集群为单位**把资源统计、监控与运维入口聚合到一个页面——每行是一个集群的"驾驶舱"，适合多集群环境的日常巡检与快速跳转。

# 页面入口

点击左侧侧边栏：【综合】→【统一管理】。

![统一管理页](images/17-01-central-list.png)

> 若菜单不可见：回[第 0 章 功能开关前置检查](00-login.md)核对权限配置。

# 界面结构

## 集群分组

集群按「分组」字段归类显示（第 1 章创建集群时的分组），支持：

- **全部展开 / 全部收起**：一键控制所有分组的折叠状态；
- 单个分组标题可点击折叠/展开。

## 集群卡片与资源统计

每个集群一行，核心是**资源统计格**：

| 统计项 | 含义 | 点击行为 |
|---|---|---|
| 节点 | `健康数 / 总数`（如 `3/3`） | 最大化并切到节点标签 |
| 上游 | 该集群上游数量 | 最大化并切到上游标签 |
| 路由 | 该集群路由数量 | 最大化并切到路由标签 |
| 插件组 | 插件组数量 | 最大化并切到插件组标签 |
| 全局规则 | 全局规则数量 | 最大化并切到全局规则标签 |

> 💡 节点格显示 `2/3` 说明有一台不健康——优先处理（排查见[第 3 章 3.4](03-edge-env.md)）。

## 最大化模式

点击卡片右上角的【最大化】图标，该集群进入全屏工作台：左侧切换节点/上游/路由等标签页，右侧为对应管理界面，免去页面间来回跳转。完成后点击【退出最大化】返回列表。

| 需求 | 推荐入口 |

# 数据备份与恢复

统一管理页面提供三种数据管理能力，位于集群卡片操作区和页面顶部。

## 导出 Excel

点击集群卡片右侧的【导出 Excel】按钮，系统将该集群的全部资源（节点、上游、路由、插件组、全局规则等）导出为 Excel 文件并自动下载。

**Excel 包含的工作表**：

| 工作表 | 内容 |
|---|---|
| 集群 | 集群基本信息（名称、描述、分组、状态） |
| 节点 | 节点 IP、SSH 端口、服务端口、健康状态 |
| 上游 | 上游名称、目标地址、协议、负载均衡方式 |
| 路由 | 路由 URI、方法、上游绑定、插件组 |
| 插件组 | 插件组名称及包含的插件列表 |
| 全局规则 | 限流、CORS、IP 黑白名单等全局规则 |
| SSL 证书 | 证书域名、颁发者、过期时间（不含私钥） |
| 静态资源 | 资源名称、绑定路由、文件大小 |
| 四层代理 | TCP/UDP 代理规则 |
| 插件元数据 | 自定义插件定义 |

> ⚠️ Excel 是**人读报表**，不含加密凭据和文件本体，不能用于程序化恢复。需要完整备份请使用【备份下载】。

## 备份下载

点击集群卡片右侧的【备份下载】按钮，系统弹出备份对话框：

1. 可选勾选「包含敏感信息」（admin_key、SSH 密码等加密字段）
2. 可选勾选「包含文件内容」（静态资源文件的 base64 编码）
3. 点击【下载备份】，系统生成 JSON 格式的完整备份文件并自动下载

**备份文件格式**：`{集群名}_backup_{日期}.json`，包含：
- 集群、节点、SSL 证书、上游、路由、插件配置、全局规则、插件元数据、四层代理、静态资源
- 元数据：版本号、导出时间、SHA-256 校验和

> 💡 备份文件可用于跨环境迁移或灾难恢复。

## 从备份恢复

点击页面顶部的【从备份恢复】按钮：

1. 选择备份 JSON 文件
2. 输入目标集群名称（不能与现有集群重名）
3. 系统校验备份格式后创建新集群（状态为「未发布」）
4. 恢复完成后需手动发布才能推送到 Edge 节点

**恢复行为**：
- 所有平台自增 ID 重新分配，不影响现有数据
- 外键关系自动重建（节点→路由→上游等）
- 敏感信息（如未勾选包含）使用空占位，发布前需补充
- 整个恢复在一个事务内完成，中途失败自动回滚

# 本章小结

- 统一管理 = 多集群驾驶舱：分组浏览 + 资源统计 + 一键跳转
- 节点健康比 `x/y` 是巡检第一信号
- 最大化模式 = 单集群全屏工作台，多标签免跳转
- Excel 导出 = 人读报表，备份下载 = 完整恢复，按需选择
