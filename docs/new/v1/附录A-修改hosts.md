# 附录 A：修改 hosts 文件（Windows）

> 适用场景：内网没有部署 DNS 服务器（或 DNS 未托管网关域名）时，在本机手动把证书域名指向网关 IP，
> 使浏览器以 `https://test.com` 形式访问网关，从而通过 HTTPS 证书的域名匹配校验（参见附录 C）。
>
> 演示环境约定：网关 `192.168.0.13`，证书域名 `test.com` / `edge.local`。请按实际环境替换。

在 Windows 系统中修改 `hosts` 文件需要**管理员权限**。以下是具体操作步骤：

### 第一步：以管理员身份打开记事本

1. 按下 `Win + S` 键打开系统搜索，输入"**记事本**"（或 Notepad）。
2. 在搜索结果中，右键点击"记事本"，选择"**以管理员身份运行**"。
3. 在弹出的用户账户控制（UAC）提示中，点击"是"。

### 第二步：打开 hosts 文件

1. 在打开的记事本窗口中，点击左上角的"**文件**" -> "**打开**"。
2. 在弹出的文件选择窗口底部，将"文件类型"从"文本文档(*.txt)"切换为"**所有文件 (*.*)**"。
3. 在地址栏中粘贴以下路径并按回车：
   `C:\Windows\System32\drivers\etc`
4. 此时你应该能看到一个名为 `hosts` 的无扩展名文件，选中它并点击"打开"。

### 第三步：添加映射记录

1. 将光标移动到文件的最末尾，换行输入以下内容：
   ```
   192.168.0.13 test.com
   192.168.0.13 edge.local
   ```
2. **格式注意**：IP 地址和域名之间至少保留一个空格或按一次 Tab 键，确保 IP 地址前没有多余的空格。
3. 点击"**文件**" -> "**保存**"（或直接按快捷键 `Ctrl + S`）。

> 💡 如果网关有多个节点（如演示环境的 192.168.0.14 / 192.168.0.15），可以为同一域名添加多条记录实现简单轮询，
> 或只保留当前使用的节点。不需要的节点请删除对应行。

### 第四步：刷新 DNS 缓存使其生效

1. 按 `Win + R` 打开运行窗口，输入 `cmd` 并回车，打开命令提示符。
2. 输入以下命令并回车：
   ```cmd
   ipconfig /flushdns
   ```
3. 看到"已成功刷新 DNS 解析缓存"后，配置即生效。

### 💡 验证是否成功

你可以在刚才的命令提示符中输入：

```cmd
ping test.com
```

如果返回的 IP 地址是 `192.168.0.13`，说明你的 hosts 文件修改已经成功生效。

```cmd
nslookup test.com
```

> ⚠️ 注意：`nslookup` **不读取 hosts 文件**，它直接查询 DNS 服务器。因此 `ping` 结果正确而 `nslookup`
> 显示其他地址属于正常现象，以 `ping` 结果为准。

---

**⚠️ 备用方案（如果直接保存依然报错）：**

如果你发现即使是以管理员身份运行记事本，保存时依然提示"拒绝访问"或无法保存，你可以采用**桌面中转法**：

1. 将 `C:\Windows\System32\drivers\etc\hosts` 文件**复制**到电脑桌面上。
2. 在桌面上用普通记事本打开它，添加映射记录并保存。
3. 将桌面上修改好的 `hosts` 文件**复制**，然后回到 `C:\Windows\System32\drivers\etc\` 目录下。
4. 在空白处右键选择"粘贴"，在弹出的提示框中选择"**替换目标中的文件**"（此时系统会要求管理员权限，点击继续即可）。
