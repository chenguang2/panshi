# 第 1 章　建立集群

本章作用：**集群是磐石 Admin 管理网关的基本单元**——一组对外提供服务的 Edge 网关节点 + 它们的全部配置（路由/上游/插件/证书）都属于某个集群。后续所有资源（节点、路由、上游、插件……）创建时都要选择所属集群；发布动作也是以集群为范围、把配置推送到该集群的节点上。

一句话理解：**集群 = 一套网关配置 + 挂在它下面的若干台网关机器**。

---

## 页面入口

侧边栏「核心功能 → 集群管理」。

![空集群列表](images/01-01-cluster-list-empty.png)

右上角「+ 新建集群」按钮打开创建弹窗。

---

## 字段逐项解释

![新建集群表单](images/01-02-cluster-form.png)

| 字段 | 必填 | 规则 / 含义 |
|---|---|---|
| **名称** | ✅ | 集群的**内部标识**，只能用小写字母、数字、中划线，中划线不能在首尾。创建后用于 API 调用与配置生成，**不可修改**。例：`demo-cluster` |
| **显示名称** | ✅ | 集群的**展示名**，可用中文，列表页和下拉框里显示的是它。例：`演示集群` |
| **分组** |  | 用于给多个集群归类（如"华东"、"华北"），便于筛选。可在输入框输入新分组名并点「添加」现场创建；不填归入「未分类」 |
| **描述** |  | 备注信息，仅内部展示 |
| **Admin Key** |  | Edge 节点 Admin API 的密钥。平台通过它调用节点管理接口下发配置。**必须与 Edge 安装时设置的 key 一致**；Edge 未启用鉴权时可留空 |
| **状态** |  | `正常` / `禁用`。禁用后集群不可发布 |

> ⚠️ 常见错误：名称填了中文或大写字母会被拒绝（提示格式错误）。中文请填到「显示名称」。

---

## 操作步骤

1. 点击「+ 新建集群」。
2. 按下表填写：

| 字段 | 本手册演示值 |
|---|---|
| 名称 | `demo-cluster` |
| 显示名称 | `演示集群` |
| 分组 | （留空） |
| 描述 | `操作手册演示集群：承载 192.168.0.13-15 三台预装节点` |
| Admin Key | （留空，与演示节点保持一致） |
| 状态 | 正常 |

![填写完成的集群表单](images/01-03-cluster-form-filled.png)

3. 点击「创建」。列表出现新集群，提示「集群已创建」。

![集群创建成功](images/01-04-cluster-created.png)

✅ **验证**：列表中出现 `demo-cluster / 漏示集群`，状态正常。

---

## 本章小结

- 集群 = 配置集合 + 节点组，是一切资源的挂载点
- 名称（英文标识，不可改）与显示名称（中文展示名）是两个字段
- Admin Key 必须与 Edge 节点的实际密钥一致
