# 25. 工具箱

> 运维管理入口——【工具箱】是日常开发调试的瑞士军刀，全部为纯本地转换，输入不出本机。

## 25.1 页面入口

点击左侧侧边栏：【运维管理】→【工具箱】。

![工具箱](images/22-01-tools.png)

> 若菜单不可见：回[第 1 章 功能开关前置检查](01-login.md)核对 `tools` 开关。

## 25.2 内置工具

左侧图标列表切换工具，全部为**纯本地转换**（输入不出本机）：

| 工具 | 用途 |
| --- | --- |
| Lua 转换 | Lua 代码片段格式化/处理，配合路由自定义预处理插件（第 9 章）使用 |
| URL 编解码 | URL 编码与解码互转 |
| JSON 格式化 | JSON 压缩/美化，排查接口返回时常用 |
| SM4 加解密 | 国密 SM4 加解密计算，配合国密证书场景（第 10 章） |

每个输入/输出框都带【复制】/【粘贴】按钮。

![JSON 格式化工具](images/22-04-json-tool.png)

## 25.3 本章小结

- 工具箱 = 本地转换四件套（Lua/URL/JSON/SM4），数据不出本机
