路由管理 · 工具条修订对比（V1 / V2 / V3）

修订原因：用户实测 1366 / 1280 视口下，「全部 / GET / POST…」方法 chips 与筛选控件同行放不下，后段控件被挤换行。本轮已将 V2（chips 独立成行）套回三方案的路由页，另附 V1 / V3 两个备选，定选后统一切换。

宽度基准：内容区宽 = 视口宽 − 240px 侧边栏 − 48px 页边距 → 1280 视口 = 992px、1366 视口 = 1078px。每个变体的红色刻度线即 1280 预算线，刻度线左端 均不换行；下方示意表格为 5 行样例（列为完整 10 列，横向滚动与工具条无关）。
