分组模式「全部展开 / 全部收起」方案对比

同一条工具条（设计页 nodes.html 原样控件 + 新增折叠钮），仅折叠钮形态与位置不同。设计稿当前没有该控件，批准后需同步补进 nodes/upstreams/routes 三份设计页。

方案 A · 推荐工具条单按钮 · 上下文切换（列配置右侧）
共 27 个节点
分组平铺

当页全展开 → 显示「全部收起」；存在折叠 → 原地换成「全部展开」。仅分组模式出现，平铺模式隐藏。与集群管理页语义一致，只占 1 个钮位。

方案 B双按钮常驻（集群管理页现形态）
共 27 个节点
分组平铺

两枚都常驻、按状态置灰（示例：全展开时「全部展开」不可用）。更直白，但右簇多占 1 个钮位，1310px 卡宽下与列配置/切换器较挤。

方案 C并入「分组 | 平铺」分段器（不推荐）
共 27 个节点
分组平铺全部收起

把动作塞进「视图模式」分段器：同一控件里既有互斥的模式选择又有一次性动作，语义混淆；且该 seg 为三页共用样式，改动会波及上游/路由两页。

语义（三方案共用）：作用范围 = 当页已加载的组；「全部收起」把当页所有组记入折叠集合，翻页后新出现的组默认展开（避免翻页后空白）；「全部展开」清空全部折叠记忆；折叠状态不持久化，刷新回默认全展开。
