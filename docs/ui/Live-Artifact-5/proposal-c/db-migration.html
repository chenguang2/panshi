数据迁移

在 SQLite 与 PostgreSQL 之间单向快照迁移，支持实时进度、进行中状态恢复与迁移历史管理；迁移期间全局写暂停，请避开业务高峰。

当前活动库SQLite本机 SQLite（开发） 可用连接3

迁移任务

单向快照替换：先备份源库，再清空目标库写入
替换模式 · 目标库现有数据将被清空覆盖，不可撤销
单阶段超时
风险与说明
  • 替换模式：目标库现有数据将被清空覆盖，不可撤销
  • 迁移前自动备份源库，备份保留最近 10 份，超量自动清理
  • 迁移期间所有写操作锁定（503），完成后自动恢复
  • 静态资源文件存储于服务器磁盘，仅部署该文件的本机可访问；迁移/切换数据库不影响静态资源文件。
