平台自建 CA 的信任锚点 · 可放心分发给最终用户安装

✓
CA 根证书可以放心下载分发给用户

这是让各内部系统显示「安全」的正确选择：用户只需安装根证书（单文件 .crt，不含任何私钥），即可信任平台签发的全部服务器证书。服务器证书本身不需要、也不应该分发给用户。

📥 用户安装指引 四个安装环境 + 通用验证 · 点此展开
🪟Windows系统级安装
1
双击下载的 .crt 文件 → 点「安装证书」
2
存储位置选「本地计算机」→ 下一步
用户账户控制（UAC）弹窗选「是」
3
选「将所有的证书都放入下列存储」→ 浏览 →「受信任的根证书颁发机构」→ 完成
4
重启浏览器生效
ℹ
本卡为系统级安装：装完后 Chrome / Edge 及其它内网软件即已信任。如需在浏览器内单独导入，见「Chrome / Edge 浏览器」卡。
🍎macOS钥匙串 · 含 Safari
1
双击 .crt 打开「钥匙串访问」→ 选「系统」钥匙串 → 添加
2
双击该证书 → 展开「信任」→ 选「始终信任」
3
关闭设置窗口，输入开机密码确认
ℹ
Safari 及系统级应用导入即生效。
🌐Chrome / Edge 浏览器全平台 · 浏览器内导入
1
地址栏输入 chrome://settings/security（Edge 为 edge://settings/privacy）
或菜单：设置 → 隐私与安全 → 安全
2
滚动到「高级」→ 点「管理证书」
3
切到「证书颁发机构」→ 点「导入」选择 .crt 文件
4
勾选「信任此 CA 标识网站」→ 确定，重启浏览器生效
ℹ
Windows 下点「导入」会打开系统导入向导，按「Windows」卡步骤操作即可；已完成系统级安装的，浏览器通常已自动信任，本卡用于需在浏览器内单独管理证书的场景。
🐧LinuxDebian / Ubuntu · RHEL 兼容
1
复制证书到系统 CA 目录
sudo cp <证书名>.crt /usr/local/share/ca-certificates/
2
更新系统证书索引
sudo update-ca-certificates
ℹ
RHEL / CentOS：复制到 /etc/pki/ca-trust/source/anchors/ 后执行 sudo update-ca-trust。
✓
如何确认安装成功（通用）：访问任一内部 HTTPS 系统（如统一管理入口），地址栏出现 🔒 且不再出现「您的连接不是专用连接」警告。若仍告警：确认装入的是「受信任的根证书颁发机构」而非「个人」存储；浏览器完全退出后重开再试。
