路由页「方法」筛选 · 三方案对比

三个方案都**取消工具条上的「全部方法」下拉**（省 110px，1440/1366 才能单行放下），差别只在第二行表现为哪种形态。
每张卡片可切换宽度档位，右下角实时显示「chips 自然宽 / 可用宽 / 是否换行」。
