# 磐石 Gateway 后台系统测试用例集

> 编制日期：2026-10-01。依据：后端实际路由与权限实现（`backend/app/api/v1/`、`app/core/deps.py`）、系统约定（AGENTS.md 关键约定）、既有自动化守卫测试。用例描述系统**当前真实行为**；标注「现状记录」的条目为已接受的已知限制，测出相同结果不算缺陷。

## 1. 使用说明

- 编号规则：`TC-<模块缩写>-<两位序号>`，模块缩写见各章标题括号内。
- 优先级：P0 = 核心流程/安全/数据完整性，必须通过；P1 = 异常/边界/状态机，重要；P2 = 列表细节/低频/体验。
- 用例类型受控词汇：功能、异常、边界值、参数校验、权限、安全、状态机、导入导出、审计、幂等、列表查询、性能、并发。
- 默认账号：`admin / panshi123`（seed，id=1，role=admin）。前端 `http://localhost:12345`，后端 API 前缀 `/api/v1`。
- 权限模型：权限为**资源级**（`role=admin` 直通；普通用户按 `UserPermission.enabled=1` 的资源键放行，否则 403）。系统无行级/集群级数据隔离，跨集群行级数据权限类用例不适用。
- 审计：变更类（mutating）请求自动写 `sys_audit_log`，查询入口为 系统管理 → 操作日志（`GET /system/operations`，`audit_logs` 权限键）。
